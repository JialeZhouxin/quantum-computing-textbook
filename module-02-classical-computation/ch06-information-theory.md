## 3.1 信息与不确定性

### 3.1.1 信息是什么？

先问一个看似简单的问题：**信息是什么？**

你可能觉得这问题太抽象了。信息不就是消息、数据、知识吗？没错，但这些都不是严格的定义。信息论的创始人克劳德·香农（Claude Shannon）在1948年给出了一个革命性的答案：

> **信息 = 不确定性的消除**

这话什么意思？让我们用一个生活场景来理解。

**场景一：你等成绩**

假设你刚考完一门课。成绩还没出来，你有四种可能的等级：优、良、中、不及格。这四种可能性谁也不知道会是哪一个——这就是**不确定性**。

突然，你的手机响了，一条短信说："你及格了！"

这条短信消除了多少不确定性？它排除了"不及格"这一种可能，但还有优、良、中三种可能。所以，这条短信包含了一定的**信息量**，但不是全部。

紧接着，又一条短信来了："你是优秀！"

哇！这条短信消除了所有剩余的不确定性。它包含的信息量比上一条更大。

这个例子想说明什么？**信息的作用就是减少不确定性。** 不确定性越大，消除它所需的信息量就越大。

**小练习**：用自己的话解释"信息 = 不确定性的消除"的含义。

### 3.1.2 概率与信息：硬币的故事

现在我们把这个直觉数学化。关键概念是**概率**。

**例 3.1：公平硬币**

一枚公平的硬币，抛掷结果只有两种可能：正面（H）或反面（T），每种概率都是 $1/2$。

- 在你抛之前：你完全不确定结果 → 不确定性大
- 抛之后：你看到了结果 → 不确定性完全消除

我们说这次抛掷提供了 **1 比特（bit）** 的信息。

> **为什么叫"比特"？**
>
> 比特（bit）是 binary digit（二进制数字）的缩写。因为抛硬币的结果可以用一个二进制数字来表示：0 代表正面，1 代表反面（或反过来）。一个二进制数字就是 1 bit。

**例 3.2：不公平的硬币**

现在换一枚"作弊"的硬币。它正面朝上的概率是 $90\%$，反面朝上的概率只有 $10\%$。

这种情况下，你猜结果是什么？大概率是正面。你的**不确定性**比公平硬币小得多——因为你知道"正面"的可能性远大于"反面"。

所以，当你真正看到结果时，这枚硬币提供的信息**少于** 1 bit。为什么？因为结果很大程度上是"意料之中"的，你并没有消除多少不确定性。

这个直觉告诉我们：**一个事件发生的概率越大，它包含的信息量越少。**

**小练习**：一枚公平硬币抛掷结果的信息量是多少？不公平硬币呢？

### 3.1.3 生活中的信息量实例

让我们把目光投向日常生活，看看信息量的概念无处不在。

**例 3.3：天气预报**

天气预报说明天"有雨"或"晴"。如果在你所在的城市，晴天概率是 $90\%$，雨天概率只有 $10\%$，那么"天晴"这条消息包含的信息量很小（意料之中），而"下雨"这条消息包含的信息量很大（意料之外）。

这正是为什么"反常"的新闻往往吸引我们的注意力——因为它包含的信息量大！"狗咬人"不是新闻（概率高、信息少），"人咬狗"才是新闻（概率低、信息量大）。

**例 3.4：选择题考试**

一道四个选项的选择题，你完全不会做，只能瞎猜。正确答案是 A、B、C、D 中的任何一个，概率都是 $1/4$。

当你得知正确答案是 C 时，你消除了多少不确定性？答案是 **2 bit**（因为需要 2 个二进制数字来区分四个选项：00=A, 01=B, 10=C, 11=D）。

所以，这道题如果完全随机猜，正确选项包含 2 bit 的信息。

但如果你已经排除了 A 和 B，只剩下 C 和 D 两个可能，那么得知答案是 C 只包含 1 bit 的信息。

**例 3.5：期末考试的不确定性**

一个学期结束了，你面临 5 门课的期末考试。每门课的成绩等级有 5 种（优秀、良好、中等、及格、不及格）。

在没有收到任何成绩之前，你的总不确定性有多大？一个简单的思路：每门课的成绩需要多少信息来表示？

5 种等级至少需要 $\lceil \log_2 5 \rceil = 3$ bit（因为 $2^2=4<5$，$2^3=8>5$）。所以每门课的成绩大约需要 3 bit。5 门课总共就是大约 15 bit 的信息量。

当所有成绩公布后，你消除了 15 bit 的不确定性。

**例 3.6：微信消息中的信息**

你在微信上给朋友发了一条"在吗？"，对方回复"在"。这条回复的信息量很小，因为你大概率知道对方会回复"在"（概率高，信息少）。

但如果对方回复"我在火星上！"，这信息量就大了！因为这件事发生的概率极低。

> **思考题**
>
> 你收到两条短信：
> 1. "明天太阳照常升起。"
> 2. "明天太阳爆炸了。"
>
> 哪一条包含的信息量大？为什么？
>
> （答案：第二条。因为太阳爆炸的概率极低，它消除了极大的不确定性。）

**小练习**：天气预报中"晴天"和"暴雨"哪个信息量大？为什么？

### 3.1.4 信息的数学化第一步

我们已经建立了一个直观：**信息量取决于事件发生的概率**。概率越小，信息量越大。

让我们尝试用一个公式来表达这种关系。假设事件 $x$ 发生的概率是 $p(x)$，那么它所携带的信息量 $I(x)$ 应该满足：

1. 如果 $p(x)=1$（必然事件），那么 $I(x)=0$（没有信息，因为没有任何不确定性）。
2. 如果 $p(x)$ 越小，$I(x)$ 越大。
3. 如果两个事件 $x$ 和 $y$ 是独立的，那么它们同时发生所包含的信息量应该等于各自信息量之和：$I(x,y) = I(x) + I(y)$。

香农证明了，满足这三个条件的唯一函数形式是：

$$I(x) = \log_b \frac{1}{p(x)} = -\log_b p(x)$$

通常我们取 $b=2$，这样信息量的单位就是比特（bit）。这个 $I(x)$ 被称为**自信息（self-information）**。

$$I(x) = -\log_2 p(x)$$

**例 3.7：计算自信息**

- 公平硬币正面：$p=1/2$，$I(H) = -\log_2(1/2) = \log_2 2 = 1$ bit ✓
- 偏置硬币正面：$p=9/10$，$I(H) = -\log_2(0.9) \approx 0.152$ bit
- 偏置硬币反面：$p=1/10$，$I(T) = -\log_2(0.1) \approx 3.322$ bit
- 选择题（4选1）正确答案：$p=1/4$，$I = -\log_2(1/4) = 2$ bit ✓

看，我们的直觉被完美地数学化了！

> **小贴士**
>
> 如果你不熟悉对数，这里有一个速成指南：
> - $\log_2 1 = 0$
> - $\log_2 2 = 1$
> - $\log_2 4 = 2$
> - $\log_2 8 = 3$
> - $\log_2 \frac{1}{2} = -1$
>
> 所以 $-\log_2 p$ 就是"以 2 为底，$1/p$ 的对数"。$p$ 越小，$1/p$ 越大，$\log_2(1/p)$ 越大。

**小练习**：自信息公式 I(x) = -log₂ p(x) 为什么用对数？

### 3.1.5 为什么是"对数"？

你可能会问：为什么偏偏是对数？前面提到的三个条件中，最关键的是第三条——**独立事件的信息量相加**。

举个例子：
- 抛两次公平硬币，结果分别是正面和反面。
- 第一次的信息量：$-\log_2(1/2) = 1$ bit
- 第二次的信息量：$-\log_2(1/2) = 1$ bit
- 两次总信息量：$2$ bit

两个独立事件同时发生的概率是各自概率的乘积：$p(HH) = p(H) \times p(H) = 1/4$。

而 $\log(ab) = \log a + \log b$，这正是我们需要的性质！

所以对数函数 $\log(1/p)$ 是唯一满足"概率相乘、信息相加"的函数。

**小练习**：独立事件的信息量为什么可以相加？这与对数性质有何关系？

> **本节小结**
>
> - 信息是不确定性的消除。
> - 信息量取决于事件发生的概率，概率越小信息量越大。
> - 自信息公式：$I(x) = -\log_2 p(x)$（单位：比特）。
> - 对数性质使得独立事件的概率相乘、信息相加。

## 3.2 香农熵

### 3.2.1 从自信息到熵

上一节我们学会了计算**单个事件**的信息量。但一个随机事件有很多种可能的结果，我们更想知道的是：**平均而言**，这个随机事件包含多少信息？

这就是**香农熵（Shannon entropy）** 的概念。

**直观定义**：香农熵是一个随机变量所有可能结果的自信息的**平均值**（期望值）。

**公式**：

$$H(X) = -\sum_{x \in \mathcal{X}} p(x) \log_2 p(x)$$

其中 $X$ 是一个随机变量，$\mathcal{X}$ 是所有可能取值的集合，$p(x)$ 是 $X = x$ 的概率。

> **名字的由来**
>
> 为什么叫"熵"（entropy）？香农在决定名字时，曾咨询过数学家冯·诺依曼。冯·诺依曼说："叫它熵吧，因为统计力学已经在用了，而且没人真正理解熵是什么，所以你在讨论中会永远占上风。"——这当然是个玩笑，但名字确实保留了下来。

**小练习**：香农熵与自信息有什么区别和联系？

### 3.2.2 熵的直觉：三个硬币的故事

让我们用三种不同的硬币来理解熵。

**例 3.8：三种硬币**

| 硬币类型 | 正面概率 | 反面概率 |
|---------|---------|---------|
| 硬币 A（公平） | 0.5 | 0.5 |
| 硬币 B（偏正面） | 0.9 | 0.1 |
| 硬币 C（确定性） | 1.0 | 0.0 |

计算它们的熵：

**硬币 A：**
$$H = -0.5 \log_2 0.5 - 0.5 \log_2 0.5 = -0.5 \times (-1) - 0.5 \times (-1) = 0.5 + 0.5 = 1 \text{ bit}$$

**硬币 B：**
$$H = -0.9 \log_2 0.9 - 0.1 \log_2 0.1$$
$$= -0.9 \times (-0.152) - 0.1 \times (-3.322)$$
$$= 0.137 + 0.332 = 0.469 \text{ bit}$$

**硬币 C：**
$$H = -1.0 \log_2 1.0 - 0.0 \log_2 0.0$$
注意：$\log_2 1 = 0$，且约定 $0 \log_2 0 \equiv 0$（因为极限 $\lim_{p \to 0} p \log_2 p = 0$）。
$$H = 0 + 0 = 0 \text{ bit}$$

**分析：**
- 硬币 A（公平）的熵是 1 bit——这是抛掷一枚公平硬币的信息量。
- 硬币 B（偏正面）的熵是 0.469 bit < 1 bit——因为我们已经有了一定的倾向性，不确定性减少了。
- 硬币 C（确定性）的熵是 0——因为结果完全确定，没有任何不确定性。

**关键直觉：**

熵衡量的是**不确定性**的程度。熵越大，不确定性越大。熵为 0 意味着完全确定。

> **记忆口诀**
>
> 熵 = 平均惊讶程度。当你看到一个结果时，你有多"惊讶"？公平硬币的结果总是让人有 50-50 的惊讶；偏正面硬币出现反面时让人惊讶，但出现正面时不太惊讶；确定硬币的结果从不让人惊讶。

**小练习**：公平硬币的熵是多少？偏置硬币（正面概率0.9）呢？

### 3.2.3 熵的更多实例

**例 3.9：骰子**

一个公平的六面骰子，各面概率均为 $1/6$。

$$H = -\sum_{i=1}^6 \frac{1}{6} \log_2 \frac{1}{6} = 6 \times \left(-\frac{1}{6} \log_2 \frac{1}{6}\right) = -\log_2 \frac{1}{6} = \log_2 6 \approx 2.585 \text{ bit}$$

也就是说，抛一个骰子的结果平均包含约 2.585 bit 的信息。

**例 3.10：天气预报**

某城市天气概率分布如下：

| 天气 | 概率 |
|-----|------|
| ☀ 晴天 | 0.5 |
| ☁ 多云 | 0.25 |
| 🌧 雨天 | 0.15 |
| ⛈ 暴雨 | 0.10 |

$$H = -0.5 \log_2 0.5 - 0.25 \log_2 0.25 - 0.15 \log_2 0.15 - 0.10 \log_2 0.10$$

$$= -0.5 \times (-1) - 0.25 \times (-2) - 0.15 \times (-2.737) - 0.10 \times (-3.322)$$

$$= 0.5 + 0.5 + 0.411 + 0.332 = 1.743 \text{ bit}$$

这个城市的天气平均需要 1.743 bit 来描述。

### 3.2.4 熵的最大值——均匀分布

现在我们问一个有趣的问题：对于有 $n$ 种可能结果的随机变量，熵的最大值是多少？

答案是当所有结果等概率时，熵取最大值：

$$H_{\max} = \log_2 n$$

证明的直观思路：均匀分布时，不确定性最大。任何偏向性的信息都会减少不确定性。

**例 3.11：2 种结果**

- 公平（$p=0.5$）：$H = 1$ bit = 最大值
- 不公平（偏一边）：$H < 1$ bit

**例 3.12：4 种结果**

- 均匀（各 $p=0.25$）：$H = \log_2 4 = 2$ bit = 最大值
- 不均匀：$H < 2$ bit

**图 3.1（想象）：** 二值随机变量的熵随概率 $p$ 的变化曲线。当 $p=0$ 或 $p=1$ 时，$H=0$；当 $p=0.5$ 时，$H=1$ 达到最大值。曲线呈倒钟形。

> **重要性质**
>
> 香农熵具有以下基本性质：
> 1. 非负性：$H(X) \geq 0$
> 2. 有界性：$H(X) \leq \log_2 |\mathcal{X}|$，$|\mathcal{X}|$ 是可能结果的数量
> 3. 达到最大值当且仅当 $X$ 是均匀分布
> 4. $H(X) = 0$ 当且仅当 $X$ 是确定性的（只有一个结果概率为 1）

### 3.2.5 联合熵

现在我们考虑**两个**随机变量。比如，抛两枚硬币：硬币 A 和硬币 B。

**定义 3.1**：联合熵 $H(X,Y)$ 衡量的是 $(X,Y)$ 这个**联合随机变量**的不确定性。

$$H(X,Y) = -\sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} p(x,y) \log_2 p(x,y)$$

其中 $p(x,y)$ 是 $X=x$ 且 $Y=y$ 的联合概率。

**例 3.13：两枚公平硬币**

抛两枚公平的独立硬币，结果有 4 种组合：HH、HT、TH、TT，每种概率 $1/4$。

$$H(X,Y) = -4 \times \frac{1}{4} \log_2 \frac{1}{4} = -\log_2 \frac{1}{4} = \log_2 4 = 2 \text{ bit}$$

注意：单枚硬币的熵是 1 bit，两枚独立硬币的联合熵是 2 bit。这符合"独立事件信息相加"的直觉。

**例 3.14：两个相关的随机变量**

假设我们有两个相关的变量：是否下雨（$X$）和是否带伞（$Y$）。概率分布如下：

| $p(x,y)$ | $Y=带伞$ | $Y=没带伞$ |
|---------|---------|-----------|
| $X=下雨$ | 0.35 | 0.05 |
| $X=没雨$ | 0.15 | 0.45 |

$$H(X,Y) = -[0.35\log_2 0.35 + 0.05\log_2 0.05 + 0.15\log_2 0.15 + 0.45\log_2 0.45]$$

$$= -[0.35 \times (-1.515) + 0.05 \times (-4.322) + 0.15 \times (-2.737) + 0.45 \times (-1.152)]$$

$$= 0.530 + 0.216 + 0.411 + 0.518 = 1.675 \text{ bit}$$

而如果我们只看 $X$（是否下雨），边缘概率为 $p(下雨)=0.4$，$p(没雨)=0.6$：

$$H(X) = -0.4 \log_2 0.4 - 0.6 \log_2 0.6 = -0.4 \times (-1.322) - 0.6 \times (-0.737) = 0.529 + 0.442 = 0.971 \text{ bit}$$

同样 $H(Y) = -0.5\log_2 0.5 - 0.5\log_2 0.5 = 1 \text{ bit}$

注意 $H(X,Y) \leq H(X) + H(Y)$，等号成立当且仅当 $X$ 和 $Y$ 独立。这里 $1.675 < 0.971 + 1$，说明 $X$ 和 $Y$ 不是独立的（这很合理——下雨概率会影响带伞概率）。

### 3.2.6 条件熵

条件熵 $H(Y|X)$ 衡量的是：在已知 $X$ 的情况下，$Y$ 还有多少不确定性。

$$H(Y|X) = \sum_{x \in \mathcal{X}} p(x) H(Y|X=x)$$

其中 $H(Y|X=x)$ 是在 $X=x$ 的条件下 $Y$ 的熵：

$$H(Y|X=x) = -\sum_{y \in \mathcal{Y}} p(y|x) \log_2 p(y|x)$$

**链式法则（Chain Rule）：**

$$H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)$$

这个公式非常直观：两个变量联合的不确定性 = 第一个变量的不确定性 + 知道第一个后第二个剩余的不确定性。

继续上面的天气例子，计算 $H(Y|X)$：

- 如果下雨（$X=下雨$，$p=0.4$）：
  - $p(带伞|下雨) = 0.35/0.4 = 0.875$
  - $p(没带伞|下雨) = 0.05/0.4 = 0.125$
  - $H(Y|X=下雨) = -0.875\log_2 0.875 - 0.125\log_2 0.125$
  - $= -0.875 \times (-0.193) - 0.125 \times (-3) = 0.169 + 0.375 = 0.544 \text{ bit}$

- 如果没雨（$X=没雨$，$p=0.6$）：
  - $p(带伞|没雨) = 0.15/0.6 = 0.25$
  - $p(没带伞|没雨) = 0.45/0.6 = 0.75$
  - $H(Y|X=没雨) = -0.25\log_2 0.25 - 0.75\log_2 0.75$
  - $= -0.25 \times (-2) - 0.75 \times (-0.415) = 0.5 + 0.311 = 0.811 \text{ bit}$

$$H(Y|X) = 0.4 \times 0.544 + 0.6 \times 0.811 = 0.218 + 0.487 = 0.705 \text{ bit}$$

验证链式法则：
$$H(X) + H(Y|X) = 0.971 + 0.705 = 1.676 \text{ bit} \approx H(X,Y) = 1.675 \text{ bit}$$

（四舍五入误差范围内一致。）

**直观解释**：知道是否下雨后，带伞与否的不确定性从 1 bit 降到了 0.705 bit。也就是说，下雨的信息帮助我们减少了关于带伞的不确定性。

**小练习**：条件熵 H(Y|X) 衡量什么？链式法则如何表示联合熵？

### 3.2.7 互信息

互信息（Mutual Information）$I(X;Y)$ 衡量的是：通过知道 $Y$，$X$ 的不确定性减少了多少。

$$I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)$$

由于链式法则，还可以写成：

$$I(X;Y) = H(X) + H(Y) - H(X,Y)$$

**直观解释**：互信息是 $X$ 和 $Y$ 之间共享的信息量。如果 $X$ 和 $Y$ 独立，则互信息为 0。如果 $X$ 完全决定了 $Y$（比如 $X=Y$），互信息就是 $H(X)$（或 $H(Y)$）。

**例 3.15：天气与带伞的互信息**

$$I(X;Y) = H(Y) - H(Y|X) = 1 - 0.705 = 0.295 \text{ bit}$$

或者：
$$I(X;Y) = H(X) + H(Y) - H(X,Y) = 0.971 + 1 - 1.675 = 0.296 \text{ bit}$$

这意味着知道是否下雨能省掉约 0.3 bit 关于是否带伞的不确定性。

**例 3.16：考试与复习**

假设某门课的考试结果（$X$：通过/不通过）和复习时间（$Y$：充足/不足）之间的互信息很大。这意味着复习时间与考试成绩高度相关——知道复习时间能大大降低考试结果的不确定性。

反之，如果考试题目完全是随机的（与复习无关），那么互信息为 0。

**互信息的基本性质：**
1. 非负性：$I(X;Y) \geq 0$
2. 对称性：$I(X;Y) = I(Y;X)$
3. $I(X;Y) = 0$ 当且仅当 $X$ 和 $Y$ 独立
4. $I(X;Y) \leq \min\{H(X), H(Y)\}$

**小练习**：互信息 I(X;Y) 与条件熵的关系是什么？互信息为 0 意味着什么？

### 3.2.8 一张图总结熵、条件熵、联合熵、互信息的关系

我们可以用一张维恩图（Venn diagram）来直观理解这些量之间的关系：

```
        ┌─────────────────────┐
        │      H(X,Y)         │
        │  ┌─────┐ ┌─────┐   │
        │  │H(X) │ │H(Y) │   │
        │  │     │ │     │   │
        │  │ I(X;Y)  │   │   │
        │  │  ←→  │ │     │   │
        │  └─────┘ └─────┘   │
        │  H(X|Y)   H(Y|X)   │
        └─────────────────────┘
```

- $H(X)$ 和 $H(Y)$ 是两个圆圈，表示各自的不确定性。
- 重叠部分是互信息 $I(X;Y)$——两个变量共享的信息。
- $H(X)$ 中不重叠的部分是 $H(X|Y)$——知道 $Y$ 后 $X$ 仍然存在的不确定性。
- $H(Y)$ 中不重叠的部分是 $H(Y|X)$。
- 大圆是联合熵 $H(X,Y)$，等于所有部分之和。

> **本节小结**
>
> - 香农熵 $H(X) = -\sum p(x) \log_2 p(x)$ 是平均信息量（平均不确定性）。
> - 均匀分布时熵最大，确定性时熵为 0。
> - 联合熵 $H(X,Y)$ 衡量两个变量的联合不确定性。
> - 条件熵 $H(Y|X)$ 衡量知道 $X$ 后 $Y$ 剩余的不确定性。
> - 互信息 $I(X;Y) = H(X) - H(X|Y)$ 衡量两个变量共享的信息。
> - 链式法则：$H(X,Y) = H(X) + H(Y|X)$。

## 3.3 信源编码

### 3.3.1 问题：如何高效地存储信息？

假设你要把一本书存到电脑里。如果每个汉字用固定编码（比如 Unicode 用 2 字节），那很简单——但有没有可能用更少的存储空间呢？

答案是：**可以！** 这就是信源编码（Source Coding）的任务——用尽可能少的比特数来表示信息。

**例 3.17：摩尔斯电码**

摩尔斯电码就是一个经典的信源编码例子。英文字母中，最常用的字母 E 被编码为最短的码字（"."），而不常用的字母 Q 被编码为较长的码字（"--.-"）。

这种思想就是：**高频信息用短编码，低频信息用长编码**，从而平均码长最短。

### 3.3.2 变长编码与哈夫曼编码

**例 3.18：一个简单消息**

假设我们要传输一条消息，它只包含 4 个字母：A、B、C、D，概率分布如下：

| 字母 | 概率 |
|-----|------|
| A | 0.5 |
| B | 0.25 |
| C | 0.125 |
| D | 0.125 |

**方案一：定长编码**
每个字母用 2 位二进制表示（因为 $2^2=4$）：A=00, B=01, C=10, D=11
平均码长 = 2 bit/字母

**方案二：变长编码（哈夫曼编码）**
利用概率分布，给高频字母分配短码：
A=0, B=10, C=110, D=111
平均码长 = $0.5 \times 1 + 0.25 \times 2 + 0.125 \times 3 + 0.125 \times 3 = 0.5 + 0.5 + 0.375 + 0.375 = 1.75$ bit/字母

**节省了 12.5% 的空间！**

计算这个分布的熵：
$$H = -0.5\log_2 0.5 - 0.25\log_2 0.25 - 0.125\log_2 0.125 - 0.125\log_2 0.125$$
$$= 0.5 + 0.5 + 0.375 + 0.375 = 1.75 \text{ bit}$$

**重要发现**：平均码长 = 熵！这不是巧合——当编码方案达到最优时，平均码长恰好等于信源的熵。

### 3.3.3 无噪声编码定理（香农第一定理）

香农证明了信息论中第一个重要的定理：

> **无噪声编码定理（Shannon's Noiseless Coding Theorem）**
>
> 对于一个离散无记忆信源，其熵为 $H$。那么可以用任意接近 $H$ 的平均码长进行无损压缩，但不可能用小于 $H$ 的平均码长进行无损压缩。

通俗地说：
- **下限**：无损压缩的最短平均码长不能小于信源的熵 $H$。
- **可达性**：存在编码方案使得平均码长可以任意接近 $H$。

这个定理告诉我们：**熵 $H$ 是无损压缩的理论极限。**

**例 3.19：文本文件压缩**

一个英文文本文件，每个字符的熵大约在 4-5 bit 左右（考虑到英文的不均匀分布和字符间的相关性）。所以用 8-bit ASCII 存储英文文本时，理论上可以压缩到大约一半的大小。这解释了为什么 ZIP、RAR 这类压缩工具能把文本文件压缩到原始大小的 50%-60%。

**例 3.20：图像压缩**

一张照片，如果相邻像素之间高度相关（大多数自然图像都是如此），那么它的熵远小于每像素 24 bit（RGB 各 8 bit）。JPEG 等图像压缩算法利用这个原理进行有损或无损压缩。

### 3.3.4 一个完整的哈夫曼编码例子

让我们用哈夫曼算法构建最优编码树。

**例 3.21：学生成绩分布**

某门课的成绩分布如下：

| 等级 | 概率 |
|-----|------|
| 优 | 0.1 |
| 良 | 0.3 |
| 中 | 0.4 |
| 及格 | 0.15 |
| 不及格 | 0.05 |

**哈夫曼编码步骤：**

1. 按概率从小到大排序：不及格(0.05)、优(0.1)、及格(0.15)、良(0.3)、中(0.4)
2. 合并两个最小的：不及格+优 = 0.15
3. 新的集合：及格(0.15)、[不及格+优](0.15)、良(0.3)、中(0.4)
4. 合并两个最小的：及格(0.15) + [不及格+优](0.15) = 0.3
5. 新的集合：良(0.3)、[及格+不及格+优](0.3)、中(0.4)
6. 合并两个最小的：良(0.3) + [及格+不及格+优](0.3) = 0.6
7. 最后合并中(0.4) + [全部] = 1.0

构建的编码树对应如下编码（从根到叶）：

| 等级 | 编码 | 位数 |
|-----|------|------|
| 中 | 0 | 1 |
| 良 | 10 | 2 |
| 及格 | 110 | 3 |
| 优 | 1110 | 4 |
| 不及格 | 1111 | 4 |

平均码长 = $0.4 \times 1 + 0.3 \times 2 + 0.15 \times 3 + 0.1 \times 4 + 0.05 \times 4$
= $0.4 + 0.6 + 0.45 + 0.4 + 0.2 = 2.05$ bit

信源熵：
$$H = -0.4\log_2 0.4 - 0.3\log_2 0.3 - 0.15\log_2 0.15 - 0.1\log_2 0.1 - 0.05\log_2 0.05$$
$$= 0.529 + 0.521 + 0.411 + 0.332 + 0.216 = 2.009 \text{ bit}$$

平均码长 2.05 bit 非常接近熵 2.009 bit。

### 3.3.5 与量子信息中熵的类比

看到这里，你可能会好奇：这些经典信息论的概念在量子信息中对应什么？

**经典 → 量子的对应关系：**

| 经典概念 | 量子概念 |
|---------|---------|
| 香农熵 $H$ | 冯·诺依曼熵 $S(\rho)$ |
| 概率分布 $p(x)$ | 密度算子 $\rho$ |
| 随机变量 $X$ | 量子态 |
| 联合熵 $H(X,Y)$ | $S(\rho_{AB})$ |
| 条件熵 $H(X\|Y)$ | $S(\rho_{AB}) - S(\rho_B)$ |
| 互信息 $I(X;Y)$ | 量子互信息 $I(A;B)$ |

在量子力学中，冯·诺依曼熵（von Neumann entropy）定义为：

$$S(\rho) = -\text{Tr}(\rho \log_2 \rho)$$

其中 $\rho$ 是密度算子。当量子态是纯态时，$S(\rho) = 0$（确定性的）；当量子态是最大混合态时，熵取最大值。

> **量子信息论的伏笔**
>
> 你现在学到的经典信息论知识，在量子章节中会一一"复活"。量子纠错、量子信道容量、量子密码学……都建立在这些基础之上。当你学到模块五和模块六时，不妨回头看看这一章，会发现它们之间的联系如此紧密。

> **本节小结**
>
> - 信源编码研究如何高效表示信息。
> - 变长编码（如哈夫曼编码）利用概率分布实现压缩。
> - 无噪声编码定理：熵 $H$ 是无损压缩的理论下限。
> - 平均码长可以任意接近 $H$ 但不能小于 $H$。
> - 经典信息论的概念在量子信息中都有对应版本。

## 3.4 信道与信道容量

### 3.4.1 通信的基本模型

每天我们都在通信——发微信、打电话、看视频。但从信息论的角度看，所有通信系统都可以用一个简单模型来概括：

```
信源 → 编码器 → 信道 → 解码器 → 信宿
                    ↓
                 噪声
```

**核心元素：**
- **信源**：产生信息的人或设备
- **编码器**：将信息转换为适合信道传输的形式
- **信道**：信息传输的物理媒介（光纤、无线电波、网线……）
- **噪声**：信道中不可避免的干扰
- **解码器**：从接收到的信号中恢复信息
- **信宿**：最终接收信息的人或设备

**例 3.22：打电话**
- 信源：你说话的声音
- 编码器：话筒将声波转换为电信号
- 信道：电话线（或无线信号）
- 噪声：线路杂音、信号衰减
- 解码器：听筒将电信号还原为声波
- 信宿：对方听到的声音

**例 3.23：微信收发消息**
- 信源：你打的字
- 编码器：手机将文字编码为数字信号（4G/5G）
- 信道：电磁波通过空气和基站传输
- 噪声：信号干扰、丢包
- 解码器：对方手机将数字信号还原为文字
- 信宿：对方看到的文字

### 3.4.2 信道的数学建模

在数学上，一个信道可以看作一个**条件概率分布** $p(y|x)$，表示当发送 $x$ 时接收到 $y$ 的概率。

**例 3.24：二进制对称信道（Binary Symmetric Channel, BSC）**

这是最基本也是最重要的信道模型之一。

```
输入 {0,1} ───→ 输出 {0,1}
    0 ────────→ 0  (概率 1-p)
    0 ──┐       → 1  (概率 p)      
    1 ──┼───────→ 1  (概率 1-p)
         └──────→ 0  (概率 p)
```

其中 $p$ 称为**误码率（bit error rate, BER）**。$0 \leq p \leq 1$。

- 如果 $p = 0$：完美信道，输入等于输出。
- 如果 $p = 0.5$：完全随机信道，输出与输入无关。
- 如果 $p = 1$：完美"翻转"信道，输出总是输入的反面。

**例 3.25：二进制删除信道（Binary Erasure Channel, BEC）**

另一种重要的信道模型：

```
输入 {0,1} ───→ 输出 {0,1,?}
    0 ────────→ 0    (概率 1-ε)
    0 ────────→ ?    (概率 ε)
    1 ────────→ 1    (概率 1-ε)
    1 ────────→ ?    (概率 ε)
```

其中 $?$ 表示"删除"——接收方知道这个比特丢失了。$\varepsilon$ 是删除概率。

**例 3.26：Z 信道（Z Channel）**

不对称的信道：
- 0 总是正确传输（$0 \to 0$ 概率 1）
- 1 有一定概率变成 0（$1 \to 0$ 概率 $p$，$1 \to 1$ 概率 $1-p$）

这种信道模拟了某些物理场景中的非对称噪声。

### 3.4.3 信道容量：信道的"极限速率"

现在问一个核心问题：**在一个有噪声的信道上，我们最多能以多快的速度可靠地传输信息？**

信道容量（Channel Capacity）就是对这个问题的回答。

**定义 3.2**：信道容量 $C$ 是可以通过该信道可靠传输信息的**最大速率**（单位：比特/信道使用）。

$$C = \max_{p(x)} I(X;Y)$$

其中最大值是对所有可能的输入分布 $p(x)$ 取的。

这个定义非常直观：互信息 $I(X;Y)$ 衡量的是"通过观察输出 $Y$ 能获得关于输入 $X$ 的信息量"。信道容量就是通过优化输入分布能得到的最大互信息。

**例 3.27：无噪声信道**

如果一个信道没有噪声，输出完全由输入决定，那么 $I(X;Y) = H(X)$。如果输入有 $n$ 种可能，则 $C = \log_2 n$ bit/信道使用。

最简单的例子：一根无噪声的电线，输入 0 或 1，输出就是 0 或 1，$C = 1$ bit/信道使用。

**例 3.28：二进制对称信道（BSC）的容量**

对于误码率为 $p$ 的 BSC，信道容量为：

$$C_{\text{BSC}} = 1 - H(p)$$

其中 $H(p) = -p \log_2 p - (1-p) \log_2 (1-p)$ 是二元熵函数。

**验证：**
- $p = 0$（无噪声）：$C = 1 - 0 = 1$ bit/信道使用 ✓
- $p = 0.5$（完全随机）：$C = 1 - 1 = 0$ bit/信道使用 ✓（无法传任何信息）
- $p = 1$（完全翻转）：$C = 1 - 0 = 1$ bit/信道使用 ✓（翻转是已知的，翻转回来就行）

**例 3.29：BSC 容量的数值计算**

| 误码率 $p$ | 信道容量 $C$ | 含义 |
|-----------|------------|------|
| 0 | 1 bit | 完美传输 |
| 0.01 | 0.919 bit | 少量噪声影响小 |
| 0.1 | 0.531 bit | 大量噪声但仍可通信 |
| 0.25 | 0.189 bit | 接近通信极限 |
| 0.5 | 0 bit | 无法通信 |

**例 3.30：二进制删除信道（BEC）的容量**

对于删除概率为 $\varepsilon$ 的 BEC，信道容量为：

$$C_{\text{BEC}} = 1 - \varepsilon$$

- $\varepsilon = 0$：$C = 1$（完美传输）
- $\varepsilon = 0.2$：$C = 0.8$
- $\varepsilon = 1$：$C = 0$（所有信息都被删除）

为什么 BEC 的容量这么简单？因为接收方知道哪些比特被删除了（收到的是 $?$），所以只需要在未删除的比特上传输信息——而删除概率就是 $\varepsilon$。

### 3.4.4 有噪声信道编码定理（香农第二定理）

这是香农在 1948 年论文中的核心定理，也是信息论最辉煌的成就：

> **有噪声信道编码定理（Shannon's Noisy Channel Coding Theorem）**
>
> 对于一个容量为 $C$ 的信道：
> 1. 如果传输速率 $R < C$，则存在一种编码方案使得错误概率可以任意小（即可靠传输）。
> 2. 如果传输速率 $R > C$，则任何编码方案都无法避免错误，错误概率会趋于 1。
> 3. $R = C$ 是可靠传输的临界点。

这个定理有着深刻的含义：

1. **存在性**：在容量以下，我们总可以找到一种编码方式来实现任意小的错误概率。
2. **不可能性**：超过容量，无论如何编码都不可能实现可靠传输。
3. **最优化**：信道容量是可靠传输的最高极限。

但定理并没有告诉我们如何构造这样的编码——它只告诉我们**存在**这样的编码。找到实际的构造是编码理论的工作。

> **直觉理解**
>
> 想象你在一间嘈杂的房间里和朋友说话。
> - 如果环境不太吵（高容量），你可以正常说话，对方能听清。
> - 如果环境很吵（低容量），你需要放慢速度、重复关键内容（增加冗余），才能让对方听懂。
> - 如果环境极度嘈杂（容量接近 0），无论你怎么喊、怎么重复，对方都听不清。
>
> 信道容量就是"还能有效交流"的最大噪音水平。

### 3.4.5 简单纠错编码示例

在有噪声信道上传输数据，我们需要引入**冗余**来抵抗错误。最简单的例子是**重复码**。

**例 3.31：三次重复码**

将每个比特重复三次：
- 0 → 000
- 1 → 111

接收端用多数投票解码：收到 000、001、010、100 都译为 0；收到 111、110、101、011 都译为 1。

如果 BSC 的误码率 $p = 0.05$，那么单个比特译码错误的概率是：
$$P_{\text{error}} = \binom{3}{2} p^2 (1-p) + \binom{3}{3} p^3 = 3 \times 0.05^2 \times 0.95 + 0.05^3 \approx 0.00725$$

从 5% 降到了约 0.7%，错误率降低了 7 倍！

但代价是：有效传输速率从 1 bit/信道使用降到了 $1/3$ bit/信道使用。

这体现了信息论中的一个基本权衡：**可靠性和速率之间的权衡**。

### 3.4.6 经典信道 vs 量子信道

现在让我们把目光投向量子世界。

**经典信道**的输入和输出都是经典信息（比特 0 和 1）。经典信道可以用条件概率分布 $p(y|x)$ 完全描述。

**量子信道**的输入和输出都是量子态。量子信道是保留量子态（包括叠加和纠缠）的物理过程。

**几个关键区别：**

| 特性 | 经典信道 | 量子信道 |
|------|---------|---------|
| 输入 | 比特（0 或 1） | 量子态（密度算子 $\rho$） |
| 输出 | 比特 | 量子态 |
| 描述 | 条件概率 $p(y|x)$ | 完全正迹保持映射 $\mathcal{E}$ |
| 叠加 | 不允许 | 允许 |
| 纠缠 | 不存在 | 存在 |
| 克隆 | 允许 | 不可克隆定理禁止 |
| 测量 | 不破坏信息 | 通常会破坏量子态 |

**例 3.32：量子信道的简单类比**

考虑一个"量子擦除信道"：输入一个量子比特，有一定概率 $\varepsilon$ 被"擦除"（变成特殊状态 $|e\rangle$），但接收方知道哪些量子比特被擦除了。

经典擦除信道（BEC）只能传输 0 或 1，而量子擦除信道可以传输一个量子比特的叠加态，因此它的容量比经典版本大——它既能传输经典信息，也能传输量子信息。

**一个重要的直觉**：量子信道比经典信道"更强大"，因为量子态可以携带更多的信息（例如，一个量子比特通过量子隐形传态可以辅助传输 2 个经典比特的信息）。

> **本节小结**
>
> - 通信系统模型：信源 → 编码器 → 信道（含噪声）→ 解码器 → 信宿。
> - 信道用条件概率 $p(y|x)$ 建模。
> - 信道容量 $C = \max_{p(x)} I(X;Y)$ 是可靠传输的最大速率。
> - 有噪声信道编码定理：$R < C$ 可可靠传输，$R > C$ 不可能。
> - 经典信道和量子信道的根本区别在于量子信道支持叠加和纠缠。

## 3.5 纠错思想初步

### 3.5.1 为什么要纠错？

在上一节中，我们看到有噪声的信道会导致传输错误。错误率可能小（比如光缆的误码率在 $10^{-12}$ 量级），但总归存在。如果传输的是普通图片，偶尔几个比特错了可能看不出来；但如果传输的是银行转账指令或医疗数据，一个比特的错误都可能是灾难性的。

纠错码（Error Correcting Code, ECC）的核心思想是**添加冗余**，使得即使部分数据被破坏，接收端也能恢复出原始信息。

### 3.5.2 汉明距离

这是纠错码理论中最基本的概念。

**定义 3.3**：两个等长二进制字符串之间的汉明距离（Hamming distance）是对应位置上不同字符的**数量**。

**例 3.33：汉明距离计算**

- $d(0000, 1111) = 4$（所有四个位置都不同）
- $d(1010, 1001) = 2$（第三和第四位不同）
- $d(0011, 0011) = 0$（完全相同的字符串）

**例 3.34：日常生活中汉明距离**

假设你朋友的名字是"张三"，但对方输成了"张四"——这两个字符串的汉明距离是 1（只差一个字）。

如果是"张三"和"李四"，汉明距离是 2（两个字都不同）。

**汉明距离的性质：**
1. 非负性：$d(x,y) \geq 0$，等号成立当且仅当 $x=y$
2. 对称性：$d(x,y) = d(y,x)$
3. 三角不等式：$d(x,z) \leq d(x,y) + d(y,z)$

### 3.5.3 最小距离与纠错能力

对于一个纠错码，所有合法码字之间的**最小汉明距离**是衡量其纠错能力的关键参数。

> **纠错能力公式**
>
> 如果编码的最小距离为 $d_{\min}$，则：
> - 可以检测最多 $d_{\min} - 1$ 个错误
> - 可以纠正最多 $\lfloor (d_{\min} - 1)/2 \rfloor$ 个错误

**例 3.35：三次重复码**

合法码字：000 和 111。
- $d_{\min} = d(000, 111) = 3$
- 可检测：最多 $3 - 1 = 2$ 个错误
- 可纠正：$\lfloor (3 - 1)/2 \rfloor = 1$ 个错误

如果你收到 010，你发现它既不是 000 也不是 111，所以你知道出错了（检测到错误）。而且它离 000 更近（汉明距离 1）而离 111 较远（汉明距离 2），所以多数投票会纠回 0。

**例 3.36：奇偶校验码**

给每 $k$ 个数据位加一个奇偶校验位（parity bit），使总 1 的个数为偶数（或奇数）。

例如，数据 1011，加偶校验位 1（因为 1011 中有奇数个 1，加 1 使其成为偶数个），得 10111。

- 最小距离 $d_{\min} = 2$
- 可检测：最多 1 个错误
- 可纠正：0 个错误（$\lfloor (2-1)/2 \rfloor = 0$）

奇偶校验只能"发现"错误但不能定位错误。但它非常高效——只需额外加 1 个比特。

### 3.5.4 几何直观：码字空间

想象一个三维立方体，8 个顶点代表所有 3-bit 字符串（000 到 111）。汉明距离就是沿着立方体边从一个顶点到另一个顶点的最短路径长度（边的数量）。

```
           111
         /    \
        /      \
     101       110
      | \       | \
      |  001    |  010
     100 -|---- 011  |
       \  |      \  |
         000       010?
```

如果我们选择 000 和 111 作为码字，它们位于立方体的对角线上，距离 3。所有其他点是"非码字"。当收到一个错误码字时，我们寻找最近的合法码字进行纠正——这就是**最近邻解码**（Nearest Neighbor Decoding）。

### 3.5.5 汉明码（7,4）：一个真正的纠错码

1950 年，理查德·汉明发明了第一个真正的纠错码——汉明码。

**(7,4) 汉明码**：
- 输入：4 个数据位
- 输出：7 个编码位（数据位 + 3 个校验位）
- 最小距离：$d_{\min} = 3$
- 纠错能力：可纠正 1 个错误，可检测 2 个错误

**编码方式（简化版）：**

数据位 $d_1 d_2 d_3 d_4$，校验位 $p_1 p_2 p_3$，满足：

$$p_1 = d_1 \oplus d_2 \oplus d_4$$
$$p_2 = d_1 \oplus d_3 \oplus d_4$$
$$p_3 = d_2 \oplus d_3 \oplus d_4$$

编码后的 7 位序列为：$p_1 p_2 d_1 p_3 d_2 d_3 d_4$

**解码（纠错过程）：**

接收端计算三个校验和（syndrome）：
$$s_1 = p_1 \oplus d_1 \oplus d_2 \oplus d_4$$
$$s_2 = p_2 \oplus d_1 \oplus d_3 \oplus d_4$$
$$s_3 = p_3 \oplus d_2 \oplus d_3 \oplus d_4$$

如果 $(s_1 s_2 s_3) = (0,0,0)$，没有错误。
如果 $(s_1 s_2 s_3) \neq (0,0,0)$，这个三元组（二进制数）直接指示了出错的位置！

**例 3.37：汉明码纠错**

假设发送的码字是 1010101（数据位 0101，校验位 101）。

接收到的码字是 1000101（第 3 位从 1 变成了 0）。

接收方计算：
$$s_1 = 1 \oplus 0 \oplus 1 \oplus 1 = 1$$
$$s_2 = 0 \oplus 0 \oplus 0 \oplus 1 = 1$$
$$s_3 = 0 \oplus 1 \oplus 0 \oplus 1 = 0$$

$(s_1 s_2 s_3) = (1,1,0) = 6$（二进制 110 = 6），这表示第 6 位出错（注意：汉明码的位序通常从 1 开始编号）。翻转第 6 位，恢复原始数据！

> **汉明码的巧思**
>
> 汉明码之所以优雅，在于它的校验和直接给出了错误位置的二进制索引。这种"错误定位"思想在后来的量子纠错中被继承和发展——量子纠错中的"稳定子形式主义"（stabilizer formalism）就是汉明码思想的量子版本。

### 3.5.6 从经典纠错到量子纠错的桥梁

为什么我们在经典计算的章节中学习纠错？因为它为模块五的量子纠错打下了基础。

**经典纠错 → 量子纠错的对应：**

| 经典纠错 | 量子纠错 |
|---------|---------|
| 比特翻转（0↔1） | 比特翻转（$|0\rangle \leftrightarrow |1\rangle$） |
| 多位错误 | 相位翻转（$|+\rangle \leftrightarrow |-\rangle$） |
| 重复码 | 量子比特翻转码（3-qubit code） |
| 汉明码 | Steane 码、Shor 码 |
| 汉明距离 | 量子编码距离 |
| 奇偶校验 | 稳定子测量 |

**关键挑战**：量子纠错比经典纠错困难得多：
1. **不可克隆**：不能简单地重复量子比特（不可克隆定理）。
2. **测量破坏**：直接测量量子态会破坏它。
3. **连续错误**：量子错误是连续的（不只是比特翻转，还有相位错误）。
4. **退相干**：量子系统与环境相互作用导致信息丢失。

但量子纠错是可行的！这在 1990 年代中期被 Peter Shor 和 Andrew Steane 等人证明。我们会在模块五中详细介绍。

> **本节小结**
>
> - 汉明距离是对应位置不同字符的数量，是纠错码的基础。
> - 最小距离决定纠错能力：可检测 $d_{\min}-1$ 个错误，可纠正 $\lfloor (d_{\min}-1)/2 \rfloor$ 个错误。
> - (7,4) 汉明码可以纠正 1 个错误，它的校验和直接定位错误位置。
> - 经典纠错的概念（距离、奇偶校验、最近邻解码）在量子纠错中都有对应版本。
