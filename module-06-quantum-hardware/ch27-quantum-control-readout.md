# 第3章 量子控制与读出

> 前两章分别介绍了超导量子比特的物理原理和其他量子计算平台。然而，有了量子比特芯片并不足以运行量子计算——我们需要**精确地控制**每个量子比特的状态，并在计算结束后**准确地读出**结果。本章深入量子计算系统的"电子层"：任意波形发生器如何生成控制脉冲，IQ混频和单边带调制如何将基带信号搬移到微波频段，约瑟夫森参量放大器如何实现量子极限的微弱信号放大，色散读出技术如何在不破坏量子态的前提下提取信息，以及量子比特的初始化与重置方法。这些技术共同构成了量子计算机的"操控与读取"基础设施。

## 3.1 任意波形发生器（AWG）

### 3.1.1 AWG在量子计算中的角色

量子计算机的"中央处理器"——量子比特——工作在微波频段（典型3–8 GHz），需要**纳秒级精度**的模拟脉冲来控制其状态。这些脉冲并非简单的正弦波，而是具有特定包络形状、相位和频率的复杂波形。

**任意波形发生器（Arbitrary Waveform Generator, AWG）**正是生成这些波形的设备。它与普通信号发生器的关键区别在于：

- **任意波形**：不限于正弦、方波等标准波形，可生成用户自定义的任意形状
- **高时间分辨率**：采样率可达数GSa/s（吉采样点/秒），时间分辨率达到亚纳秒
- **多通道同步**：每个量子比特需要独立的控制通道，AWG提供多通道且通道间同步抖动极小（< 10 ps）
- **序列化能力**：能够按预定时序执行复杂的脉冲序列

**典型控制系统架构：**

### 3.1.2 AWG的核心技术指标

| 指标 | 典型值 | 对量子控制的影响 |
|------|--------|-----------------|
| 采样率 | 1–25 GSa/s | 决定脉冲时间分辨率 |

## 3.2 IQ混频与单边带调制

### 3.2.1 为什么需要混频？

AWG直接输出的信号是**基带信号**（典型频率DC–500 MHz），而超导量子比特的工作频率在**微波频段**（3–8 GHz）。基带信号必须被"搬移"到目标频率才能作用于量子比特。这个过程称为**上变频**。

类似地，从量子比特反射回来的读出信号也在微波频段，需要**下变频**到基带后才能被模数转换器（ADC）采样。

### 3.2.2 IQ混频器原理

**IQ混频器**是实现上/下变频的核心器件。它利用两个正交本振信号与输入信号相乘，实现频率搬移。

**为什么JPA的噪声接近量子极限？**

约瑟夫森结是**无耗散器件**（超导），其非线性电感不引入电阻热噪声。放大过程中唯一不可避免的噪声来自量子涨落——即真空态的零点能。因此JPA可以逼近量子极限。

### 3.3.6 读出系统中的放大器链

```
量子比特 → JPA（20 mK） → HEMT（4 K） → 室温放大器 → ADC
            ↑                 ↑              ↑
       增益15-30dB       增益30dB        增益40dB
       噪声~0.5量子     噪声~2K          噪声~300K
```

- **JPA**：第一级放大，将信号提升到HEMT噪声之上
- **HEMT放大器**（高电子迁移率晶体管）：工作在4 K温区，提供约30 dB增益
- **室温放大器**：进一步放大到ADC可采样电平

### 3.4.6 复用读出

现代量子处理器有数十到数百个量子比特，为每个量子比特单独配置一条读出链路不现实。**频率复用读出（Frequency-Multiplexed Readout）**解决了这个问题：

- 每个量子比特耦合到一个具有不同共振频率的谐振腔
- 一条共同的传输线同时发送多个频率的读出脉冲
- 反射信号经FFT或数字滤波器分离每个谐振腔的响应

**复用读出示意：**

```
量子比特1 ── 谐振腔1（f₁）
量子比特2 ── 谐振腔2（f₂）  
量子比特3 ── 谐振腔3（f₃）
量子比特4 ── 谐振腔4（f₄）
                        │
                   ┌────▼────┐
                   │ 公共读出线 │
                   └────┬────┘
                        │
                   ┌────▼────┐
                   │  JPA + ADC│
                   └────┬────┘
                        │
                  数字分离（FPGA）
                   f₁ f₂ f₃ f₄
```

### 3.5.5 实际系统的初始化流程

```
量子算法开始
    │
    ├─ 等待 5×T₁（被动冷却，~500 μs）
    │
    ├─ 测量所有量子比特
    │
    ├─ 对每个处于 |1⟩ 的量子比特施加 π 脉冲
    │
    ├─ 再次验证（可选）
    │
    └─ 开始算法
```

> **总结**：量子比特的初始化不再是"开了制冷机就自动好"的问题。随着量子比特数量增加和门保真度要求提升，主动重置技术成为量子计算机不可或缺的一部分。
