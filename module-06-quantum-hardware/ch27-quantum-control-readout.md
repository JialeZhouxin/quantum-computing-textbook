## 3.1 任意波形发生器（AWG）

### 3.1.1 AWG 在量子计算中的角色

量子计算机的"中央处理器"——量子比特——工作在微波频段（典型 3–8 GHz），需要**纳秒级精度**的模拟脉冲来控制其状态。这些脉冲并非简单的正弦波，而是具有特定包络形状、相位和频率的复杂波形。

**任意波形发生器（Arbitrary Waveform Generator，AWG）**正是生成这些波形的设备。它与普通信号发生器的关键区别在于：

- **任意波形**：不限于正弦、方波等标准波形，可生成用户自定义的任意形状
- **高时间分辨率**：采样率可达数 GSa/s（吉采样点/秒），时间分辨率达到亚纳秒
- **多通道同步**：每个量子比特需要独立的控制通道，AWG 提供多通道且通道间同步抖动极小（< 10 ps）
- **序列化能力**：能够按预定时序执行复杂的脉冲序列

**典型控制系统架构：**

```
量子计算控制器
┌─────────────────────────────────────────┐
│   FPGA 序列器（数字时序控制）             │
│     │  │  │  │  │  │  │  │               │
│   ┌─┴──┴──┴──┴──┴──┴──┴──┴─┐           │
│   │  AWG 1  AWG 2 ... AWG N  │  ← 模拟输出 │
│   └─┬──┬──┬──┬──┬──┬──┬──┬──┘           │
│     │  │  │  │  │  │  │  │  │             │
│     │  │  │  │  │  │  │  │  │             │
│   ┌─┴──┴──┴──┴──┴──┴──┴──┴─┐           │
│   │  混频器阵列（上变频）      │           │
│   └─┬──┬──┬──┬──┬──┬──┬──┬──┘           │
│     │  │  │  │  │  │  │  │  │             │
│     ▼  ▼  ▼  ▼  ▼  ▼  ▼  ▼              │
│   到稀释制冷机中的量子比特                 │
└─────────────────────────────────────────┘
```

### 3.1.2 AWG 的核心技术指标

**采样率（Sampling Rate）**

AWG 的采样率决定了它能生成的最大频率分量。根据奈奎斯特采样定理，AWG 能够无混叠地生成上限为采样率一半的频率分量。对于需要 3–8 GHz 载波的量子控制，通常采用**上变频方案**：AWG 在基带（DC–500 MHz）生成包络信号，然后通过 IQ 混频器搬移到微波频段。

$$
f_{\text{max}} \leq \frac{f_s}{2}
$$

其中 $f_s$ 是 AWG 采样率，$f_{\text{max}}$ 是可生成的最高频率分量。

**例 3.1** 一台采样率 $f_s = 2$ GSa/s 的 AWG，其直接输出最高频率约 1 GHz。为了控制 5 GHz 的量子比特，需要使用上变频方案。

**垂直分辨率**

AWG 的垂直分辨率（位数）决定了波形的幅度精度。量子控制需要极高的幅度精度来最小化门误差：

- 典型分辨率：14–16 bit
- 16 bit 提供 $2^{16} = 65536$ 个幅度等级
- 有效位数（ENOB）通常低于标称位数

**通道密度**

随着量子芯片规模扩展，每个量子比特需要的控制通道数成为瓶颈：

- 单比特门：每个量子比特 1–2 个通道（XY 控制）
- 读出：共用读出通道（频率复用）
- 调谐：每个量子比特 1 个 DC 偏置通道

对于 100 量子比特芯片，需要约 300 个微波控制通道。

**时序精度**

多比特量子门需要精确的时序对齐。AWG 的关键时序指标包括：

- 通道间偏斜（skew）：< 10 ps
- 抖动（jitter）：< 1 ps RMS
- 时间分辨率：采样周期的倒数

### 3.1.3 AWG 产生的典型脉冲形状

量子控制脉冲通常有特定的包络形状以最小化泄露和谱扩散。

**高斯脉冲**

最简单的脉冲形状——高斯函数：

$$
\Omega(t) = \Omega_0 \exp\left(-\frac{(t - t_0)^2}{2\sigma^2}\right)
$$

其中 $\sigma$ 控制脉冲宽度。高斯脉冲的频谱也是高斯形，具有最小的时间-带宽乘积。

**DRAG 脉冲**

Derivative Removal by Adiabatic Gate（DRAG）是一种消除泄露到非计算能级的脉冲整形技术。其核心思想是加入与高斯包络导数成正比的修正项：

$$
\Omega(t) = \Omega_{\text{Gaussian}}(t) + i\frac{\dot{\Omega}_{\text{Gaussian}}(t)}{\Delta}
$$

其中 $\Delta$ 是量子比特与泄露能级之间的失谐。DRAG 脉冲可以显著降低门误差。

**平顶高斯（Flat-top Gaussian）脉冲**

为了在中间时间段保持恒定的 Rabi 频率，可以在高斯脉冲的上升和下降沿之间插入平坦段：

$$
\Omega(t) = \text{Gaussian rising} + \text{constant} + \text{Gaussian falling}
$$

这种脉冲在超导量子比特中常用，因为它提供均匀的旋转角度。

## 3.2 IQ 混频与单边带调制

### 3.2.1 为什么需要混频？

AWG 直接生成的基带信号（DC–500 MHz）频率远低于量子比特的工作频率（3–8 GHz）。我们需要将基带信号**上变频（up-conversion）**到微波频段。同样，读出时也需要将微波信号**下变频（down-conversion）**到基带进行数字化。

**混频（mixing）**就是实现这种频率搬移的基本操作。混频器利用非线性元件的特性，将输入信号与本振（LO）信号相乘，产生和频与差频分量。

### 3.2.2 IQ 混频器原理

**IQ 混频器**使用两个混频器分别处理同相（In-phase，I）和正交（Quadrature，Q）分量，实现复信号的上变频/下变频。

**上变频过程：**

输入基带信号（I 和 Q 两路）与本振信号混频：

$$
\begin{aligned}
I(t) &: \text{基带同相分量} \\
Q(t) &: \text{基带正交分量} \\
\text{LO} &: \cos(\omega_{\text{LO}} t) \quad \text{本振信号}
\end{aligned}
$$

IQ 混频器的输出为：

$$
S_{\text{out}}(t) = I(t)\cos(\omega_{\text{LO}} t) - Q(t)\sin(\omega_{\text{LO}} t)
$$

这实际上是复信号 $(I + iQ)$ 乘以 $e^{i\omega_{\text{LO}}t}$ 的实部：

$$
S_{\text{out}}(t) = \text{Re}\left[(I(t) + iQ(t)) e^{i\omega_{\text{LO}} t}\right]
$$

**例 3.2** 如果 $I(t) = A\cos(\omega_{\text{BB}} t)$，$Q(t) = A\sin(\omega_{\text{BB}} t)$，则：

$$
S_{\text{out}}(t) = A\cos(\omega_{\text{BB}} t)\cos(\omega_{\text{LO}} t) - A\sin(\omega_{\text{BB}} t)\sin(\omega_{\text{LO}} t) = A\cos((\omega_{\text{LO}} + \omega_{\text{BB}})t)
$$

输出是频率为 $\omega_{\text{LO}} + \omega_{\text{BB}}$ 的单边带信号——**上边带**。这正是我们想要的结果。

### 3.2.3 IQ 混频产生的问题：镜像频率

如果 IQ 混频器的 I 和 Q 通道不匹配（幅度不平衡或相位不正交），就会产生**镜像频率（image frequency）**——即 $\omega_{\text{LO}} - \omega_{\text{BB}}$ 分量。

**镜像抑制比（Image Rejection Ratio，IRR）**衡量混频器抑制镜像的能力：

$$
\text{IRR} = 10\log_{10}\frac{P_{\text{desired}}}{P_{\text{image}}}\;[\text{dB}]
$$

典型的量子控制系统中，IRR 需要 > 30 dB。

**镜像产生的两个主要原因：**

1. **幅度不平衡**：I 和 Q 通道的增益不同
2. **相位误差**：90° 移相器不是精确的 90°

**例 3.3** 如果 IQ 混频器有 0.5 dB 幅度不平衡和 3° 相位误差，预计 IRR 约为 30 dB。这要求校准。

### 3.2.4 单边带调制（SSB）

**单边带调制（Single Sideband Modulation，SSB）**是上述 IQ 混频过程的正式名称。通过精确控制 I/Q 信号的相位关系，我们可以只产生上边带或只产生下边带。

**实际 SSB 实现步骤：**

1. 在 FPGA（或 AWG）中生成数字基带 I/Q 波形
2. 通过 DAC 转换为模拟 I/Q 信号
3. 送入 IQ 混频器与本振混频
4. 输出经放大和滤波后送入稀释制冷机

**边带抑制比（Sideband Suppression Ratio，SSR）**与 IRR 类似，衡量有用边带与无用边带的功率比：

$$
\text{SSR} = 10\log_{10}\frac{P_{\text{USB}}}{P_{\text{LSB}}}\;[\text{dB}]\quad\text{（对于上边带模式）}
$$

**例 3.4** 如果系统 SSR = 40 dB，无用边带功率是有用边带的 $10^{-4}$，即万分之一。

### 3.2.5 信号链完整流程

一个典型的量子控制信号链（从上到下）：

```
数字域（FPGA）:
  ┌──────────┐    ┌─────────┐    ┌───────────┐
  │ 波形生成 │ → │ 数字I/Q │ → │ DAC      │
  │ (AWG)    │    │ 上采样   │    │ (数模转换) │
  └──────────┘    └─────────┘    └───────────┘
                                         │
模拟域:                                    ▼
  ┌──────────┐    ┌─────────┐    ┌───────────┐
  │ 低通滤波 │ ← │ IQ混频器│ ← │ 模拟I/Q   │
  │ (LPF)   │    │ (上变频) │    │           │
  └──────────┘    └─────────┘    └───────────┘
       │
       ▼
  ┌──────────┐    ┌─────────┐
  │ 放大     │ → │ 衰减器   │ → 到稀释制冷机
  │ (放大器)  │    │ (可调)  │
  └──────────┘    └─────────┘
```

### 3.2.6 实际系统中的非理想因素

**I/Q 不平衡校准**

IQ 混频器的不平衡可以通过软件校准来修正。校准方法：在基带生成测试信号，测量镜像功率，然后调整补偿参数最小化镜像。

**本振泄露**

由于混频器中的直流偏置，部分本振信号会直接泄漏到输出端。可以通过在基带 I/Q 中加入直流偏移来抵消：

$$
I_{\text{corr}}(t) = I(t) - \delta I,\quad Q_{\text{corr}}(t) = Q(t) - \delta Q
$$

**相位噪声**

本振源的相位噪声会直接影响门的保真度。低相位噪声的微波源（如基于蓝宝石谐振腔的振荡器）是高质量量子控制的前提。

## 3.3 约瑟夫森参量放大器（JPA）

### 3.3.1 量子极限测量难题

量子比特的读出信号非常微弱——单个微波光子的能量在 5 GHz 时仅为 $E = h\nu \approx 3.3 \times 10^{-24}$ J，远低于传统放大器（如 HEMT）的噪声温度。

**标准量子极限（Standard Quantum Limit，SQL）**：一个线性相位不敏感放大器必须引入至少半个量子的附加噪声：

$$
T_N \geq \frac{h\nu}{k_B}
$$

在 5 GHz，这对应约 240 mK——与稀释制冷机的工作温度相当。

**传统 HEMT 放大器**的噪声温度约为 2–5 K，远超量子极限。因此，在 HEMT 之前需要一级**量子极限放大器**来放大微弱信号，使信号功率超过 HEMT 的噪声基底。

克服这一瓶颈的关键器件就是**约瑟夫森参量放大器（Josephson Parametric Amplifier，JPA）**。

### 3.3.2 物理原理：约瑟夫森结的非线性电感

JPA 的核心是约瑟夫森结。约瑟夫森结的电流-相位关系是非线性的：

$$
I = I_c \sin \phi
$$

其中 $I_c$ 是临界电流，$\phi$ 是结两端的超导相位差。这种非线性产生了**非线性电感**：

$$
L_J(\phi) = \frac{\Phi_0}{2\pi I_c \cos\phi} = \frac{L_{J0}}{\cos\phi}
$$

其中 $\Phi_0 = h/2e$ 是磁通量子，$L_{J0} = \Phi_0/(2\pi I_c)$ 是零偏置下的约瑟夫森电感。

因为电感随相位变化，振荡回路的谐振频率也可以被调节——这就是**参量作用**的基础。

### 3.3.3 参量放大机制

参量放大器的工作基于**参量泵浦**：在非线性谐振器的本征频率附近施加一个强泵浦信号，改变谐振器的有效参数（如电感或电容），从而实现信号的放大。

**简并参量放大（Degenerate Parametric Amplification）**

当泵浦频率恰好是信号频率的两倍时（$\omega_p = 2\omega_s$），发生简并参量放大。这个过程可以理解为：

- 泵浦光子（能量 $2\omega_s$）分裂为一对信号光子（各 $\omega_s$）
- 其中一个光子放大信号
- 另一个光子形成空闲模式（idler mode）

在简并模式下，JPA 可以实现**相位敏感放大**：只放大特定相位分量，对正交相位分量进行衰减。这种模式可以实现低于标准量子极限的噪声性能。

**非简并参量放大（Non-degenerate Parametric Amplification）**

当泵浦频率 $\omega_p \neq 2\omega_s$ 时，信号和空闲模式频率不同。这是**相位不敏感放大**模式，噪声必须至少为半个量子的标准量子极限。

JPA 的增益可通过泵浦功率调节。当泵浦功率接近阈值时，增益急剧增加，但也会引入更多非线性效应和压缩。

**例 3.5** 典型的 JPA 增益曲线：在泵浦功率为 -80 dBm 时增益 10 dB，泵浦功率增加 1 dB 可能使增益跳跃到 20–30 dB。

### 3.3.4 JPA 的关键性能指标

**增益（Gain）**

- 典型值：15–25 dB
- 最大值：可达 40 dB（接近阈值）
- 带宽：通常 10–100 MHz

**噪声温度**

- 接近量子极限：$T_N \approx 0.5\text{–}2$ 倍量子极限
- 典型值：0.5–2 个量子的附加噪声
- 远低于 HEMT 的 10–50 个量子

**动态范围**

- 1 dB 压缩点：$-120$ 到 $-100$ dBm
- 饱和功率：受临界电流限制

**带宽**

- 依赖于电路 Q 值
- 阻抗匹配 JPA：带宽可达 500 MHz
- 传统 JPA：10–50 MHz

### 3.3.5 JPA 的种类与演进

**阻抗匹配 JPA（IMPA）**

通过阻抗匹配网络增加带宽，是目前超导量子计算中最常用的读出放大器。带宽可达 300–700 MHz。

**行进波参量放大器（TWPA）**

利用长传输线中的非线性元件实现宽带的参量放大。TWPA 使用大量串联的约瑟夫森结（或 SNAIL 元件）构成非线性传输线，信号沿传输线传播时被连续放大。

- 带宽：可达几个 GHz
- 增益：15–20 dB
- 动态范围：优于传统 JPA

**SNAIL 放大器**

SNAIL（Superconducting Nonlinear Asymmetric Inductive eLement）使用非对称的约瑟夫森结环路来调控非线性，实现更优的压缩抑制和动态范围。

### 3.3.6 读出系统中的放大器链

实际的读出系统使用多级放大：

```
量子比特
    │
    │   (色散耦合计测量)
    ▼
谐振腔输出（-140 dBm）
    │
    ├─→ JPA（增益 20 dB）→ -120 dBm
    │
    ├─→ circulator（隔离器，防止反向噪声）
    │
    ├─→ HEMT（增益 30 dB）→ -90 dBm （4 K 温区）
    │
    └─→ 室温放大器（增益 30 dB）→ -60 dBm
            │
            ▼
         下变频 + ADC
```

**关键要点**：JPA 必须在最前端（稀释制冷机底层，~20 mK），因为任何后续放大器级的噪声都会被 JPA 的增益有效抑制。

## 3.4 色散读出技术

### 3.4.1 读出问题的本质

量子比特的读出本质上是一个**测量问题**：我们需要获取量子比特的状态（$|0\rangle$ 或 $|1\rangle$），但测量过程会不可避免地影响量子比特的状态（波函数坍缩）。

理想读出应具备以下特性：

1. **高保真度**：正确区分 $|0\rangle$ 和 $|1\rangle$ 的概率 > 99%
2. **量子非破坏（QND）**：测量后量子比特保持在可预测的状态
3. **快速**：读出时间远短于量子比特的相干时间
4. **可扩展**：能在多量子比特系统上并行实现

**色散读出（dispersive readout）**是目前超导量子计算中最广泛使用的读出方案。

### 3.4.2 色散读出的物理原理

色散读出基于**量子比特-谐振腔耦合系统**的 Jaynes-Cummings 模型。当量子比特和谐振腔之间的失谐 $\Delta = \omega_q - \omega_r$ 远大于耦合强度 $g$ 时，系统处于**色散区域**。在此区域中，有效哈密顿量为：

$$
H_{\text{eff}} = \left(\omega_r + \frac{g^2}{\Delta}\sigma_z\right) a^\dagger a + \frac{1}{2}\omega_q \sigma_z
$$

关键项是 $+\frac{g^2}{\Delta}\sigma_z a^\dagger a$：谐振腔的频率依赖于量子比特的状态：

$$
\omega_r' = \omega_r \pm \frac{g^2}{\Delta}
$$

其中 $+$ 对应量子比特处于 $|0\rangle$，$-$ 对应 $|1\rangle$。

**例 3.6** 设 $\omega_q = 5.0$ GHz，$\omega_r = 6.0$ GHz，$g = 100$ MHz，则 $\Delta = -1.0$ GHz：

$$
\frac{g^2}{\Delta} = \frac{(100\ \text{MHz})^2}{-1.0\ \text{GHz}} = -10\ \text{MHz}
$$

量子比特处于 $|0\rangle$ 时，腔频率为 $6.0 - 10 = 5.99$ GHz；处于 $|1\rangle$ 时，腔频率为 $6.0 + 10 = 6.01$ GHz。

### 3.4.3 读出过程

色散读出的完整过程如下：

1. **准备阶段**：量子比特完成量子门操作，进入待读出的状态
2. **探测阶段**：向谐振腔发送一个短的探测脉冲（典型 50–200 ns），频率在腔频率附近
3. **响应阶段**：探测脉冲从谐振腔反射或透射，其相位和幅度携带量子比特状态信息
4. **放大阶段**：信号经 JPA 和 HEMT 放大
5. **下变频与采样**：信号下变频到基带，由 ADC 数字化

探测脉冲的传输系数取决于量子比特状态：

$$
S_{21} \approx \frac{\kappa/2}{i(\omega_r \pm \chi) - \kappa/2}
$$

其中 $\kappa$ 是腔的线宽，$\chi = g^2/\Delta$ 是色散频移。

在谐振时（$\omega = \omega_r$），反射信号的相位与量子比特状态的关系：

$$
\theta_{|0\rangle} = \arctan\left(\frac{2\chi}{\kappa}\right),\quad \theta_{|1\rangle} = -\arctan\left(\frac{2\chi}{\kappa}\right)
$$

**例 3.7** 如果 $\kappa = 5$ MHz，$\chi = 10$ MHz：

$$
\theta_{|0\rangle} = \arctan(4) \approx 76^\circ,\quad \theta_{|1\rangle} \approx -76^\circ
$$

两个状态的相位差约 $152^\circ$——非常好的区分度。

### 3.4.4 读出保真度

读出保真度量化了正确识别量子比特状态的能力。在单次测量中，根据同相（I）和正交（Q）分量的二维散点图，可以定义两个类别的分离度。

**分离度（Separation）**定义为两个态在 IQ 平面上的距离除以各自标准差的平均值：

$$
\text{Sep} = \frac{|\mu_{|0\rangle} - \mu_{|1\rangle}|}{\sqrt{(\sigma_{|0\rangle}^2 + \sigma_{|1\rangle}^2)/2}}
$$

**读出保真度**近似为：

$$
F_{\text{readout}} = 1 - \frac{1}{2}\text{erfc}\left(\frac{\text{Sep}}{2}\right)
$$

**例 3.8** 分离度 Sep = 5 时：

$$
F_{\text{readout}} \approx 1 - \frac{1}{2}\text{erfc}(2.5) \approx 0.9999
$$

这对应 99.99% 的读出保真度。

提高读出保真度的方法包括：

- 增加探测脉冲长度（但会增加退相干）
- 使用 JPA 降低噪声
- 优化 IQ 平面中的状态分离
- 使用机器学习分类器

### 3.4.5 临界光子数与量子非破坏测量

探测脉冲的光子数不能任意大。当腔内光子数超过**临界光子数** $n_{\text{crit}}$ 时，色散近似失效：

$$
n_{\text{crit}} = \frac{\Delta^2}{4g^2}
$$

适用于 $n \ll n_{\text{crit}}$。

**例 3.9** 对于 $\Delta = 1.0$ GHz，$g = 100$ MHz：

$$
n_{\text{crit}} = \frac{(1.0\ \text{GHz})^2}{4 \times (100\ \text{MHz})^2} = 25
$$

因此探测脉冲的平均光子数应远小于 25。

**QND 特性**：色散读出的关键优势是它近似**量子非破坏（Quantum Non-Demolition，QND）**测量。测量算符 $\sigma_z$ 与量子比特哈密顿量对易，因此理论上测量后量子比特保持在 $\sigma_z$ 本征态。这允许：

- 重复读出提高保真度
- 测量后状态可用于后续计算
- 状态初始化（投影到 $|0\rangle$ 或 $|1\rangle$）

### 3.4.6 复用读出

在大规模量子处理器中，为每个量子比特分配独立的读出链是不现实的（布线、空间、成本限制）。**频率复用读出（frequency-multiplexed readout）**允许多个量子比特共享一条读出线。

**原理**：每个量子比特耦合到不同谐振频率的读出谐振腔（频率间隔 > 线宽），使用频率梳状探测脉冲同时读出所有量子比特。接收信号通过傅里叶变换分离各频率分量。

**关键参数**：

- 频率间隔：通常 10–50 MHz
- 最大复用数：受限于读出带宽（典型 4–8 个/线）
- 串扰：频率接近的通道间可能有串扰

**例 3.10** 在一条读出线上复用 4 个量子比特，每个腔频率间隔 20 MHz，使用 100 MHz 带宽的 JPA。总读出时间约 200 ns，同时获取 4 个量子比特的测量结果。

## 3.5 量子比特初始化与重置

### 3.5.1 初始化的挑战

量子计算要求量子比特在计算开始时处于一个已知的初始态（通常是 $|0\rangle$）。然而，在有限温度下，量子比特并不天然处于基态——它可能处在热混合态。

**热占据概率：**

量子比特在温度 $T$ 下的热激发概率为：

$$
p_{|1\rangle} = \frac{e^{-h\nu_q/k_B T}}{1 + e^{-h\nu_q/k_B T}}
$$

其中 $\nu_q$ 是量子比特频率（通常 4–6 GHz），$k_B$ 是玻尔兹曼常数。

**例 3.11** 在稀释制冷机基础温度 20 mK 下，5 GHz 量子比特的热占据率：

$$
\frac{h\nu_q}{k_B} \approx \frac{6.626 \times 10^{-34} \times 5 \times 10^9}{1.381 \times 10^{-23}} \approx 0.24\ \text{K} = 240\ \text{mK}
$$

在 20 mK（远低于 240 mK）时，$p_{|1\rangle} \approx e^{-12} \approx 6 \times 10^{-6}$——热激发基本可忽略。

但实际系统中，量子比特通过读出腔和输入线耦合到较高温度（~50 mK–1 K）的热浴，导致有效温度更高。

### 3.5.2 被动初始化：热平衡与极化

**被动冷却**是指让量子比特自然弛豫到基态。所需的弛豫时间约为 $5 \times T_1$。

**例 3.12** 一个量子比特的 $T_1 = 100$ μs，被动冷却到基态所需时间约 500 μs。这在当前处理器中是可接受的，但随 $T_1$ 延长到 ms 量级，被动冷却会显著影响重置率。

### 3.5.3 主动重置方法

**1. 测量后重置**

流程：测量量子比特 → 如果是 $|1\rangle$，施加 $\pi$ 脉冲翻转回 $|0\rangle$。

反馈延迟必须远小于量子比特的 $T_1$。在延迟期间，量子比特可能发生弛豫或退相干。

**例 3.13** 读出延迟 500 ns，$T_1 = 100$ μs，反馈重置至 $|0\rangle$ 的概率约 $1 - 500\text{ ns}/100\text{ μs} = 99.5\%$。

**2. 反馈重置（Feedback Reset）**

在 FPGA 中实时处理读出信号并决定是否施加 $\pi$ 脉冲。延迟由读出时间 + 决策时间 + 脉冲时间决定。

**3. 微波驱动重置**

通过施加特定频率的微波脉冲将 $|1\rangle$ 驱动到 $|2\rangle$ 或更高的泄露能级，利用这些能级的快速弛豫将布居数返回 $|0\rangle$。

**4. 辅助能级重置**

利用量子比特的第三个能级 $|2\rangle$，将 $|1\rangle$ 的布居通过 $|2\rangle$ 通道快速耗散到基态——需要额外的驱动和弛豫路径。

### 3.5.4 初始化保真度的量化

初始化保真度 $F_{\text{init}}$ 定义为制备到 $|0\rangle$ 的概率。典型的测量方法：

1. 准备并测量 $|0\rangle$：得到 $P(|0\rangle)$
2. 测量 $|0\rangle$ 的保真度 $F_0$
3. 测量 $|1\rangle$ 的误识别率

更严格的初始化保真度通过**层析（tomography）**测量密度矩阵 $\rho$ 并计算 $\langle 0|\rho|0\rangle$。

**例 3.14** 一个量子比特经过主动重置后的密度矩阵：

$$
\rho = \begin{pmatrix} 0.999 & 0.002 \\ 0.002 & 0.001 \end{pmatrix}
$$

初始化保真度 $F_{\text{init}} = \langle 0|\rho|0\rangle = 0.999$。

### 3.5.5 实际系统的初始化流程

典型的多量子比特初始化流程：

```
1. 等待被动冷却（50–500 μs，取决于 T1）
2. 读出所有量子比特
3. 根据读出结果决定翻转哪些量子比特（反馈延迟 ~500 ns–1 μs）
4. 施加选择性 π 脉冲
5. (可选) 重复第2–4步以提高保真度
```

总初始化时间通常为 1–5 倍 $T_1$，与量子比特数目无关（因为读出可以并行）。

> **本章小结**
>
> 1. **AWG** 是量子控制的"信号发生器"，生成纳秒级精度的基带脉冲，通过 IQ 混频器上变频到量子比特的工作频段。
> 2. **IQ 混频**通过 I/Q 通道的相位控制实现单边带调制，将基带信号搬移到微波频段。I/Q 不平衡导致镜像频率，需通过校准抑制。
> 3. **约瑟夫森参量放大器（JPA）**利用约瑟夫森结的非线性实现量子极限的微弱信号放大，是读出链的第一级关键器件。阻抗匹配 JPA（IMPA）和行进波参量放大器（TWPA）是当前的主流方案。
> 4. **色散读出**利用量子比特-谐振腔耦合系统的色散频移来非破坏性地读取量子比特状态。腔频率偏移 $\chi = g^2/\Delta$ 携带量子比特状态信息，通过反射信号的相位提取。
> 5. **频率复用读出**允许多个量子比特共享一条读出链，是大规模量子处理器的关键使能技术。
> 6. **初始化与重置**通过被动冷却、测量后反馈重置、微波驱动重置等方法将量子比特制备到 $|0\rangle$ 基态。主动重置能在远短于 $T_1$ 的时间尺度上完成初始化。
>
> 量子控制与读出系统是连接抽象的量子算法和物理量子比特的桥梁。这些技术决定了量子门操作的精度、读出的保真度和系统的可扩展性——它们和量子比特硬件本身一样重要。
