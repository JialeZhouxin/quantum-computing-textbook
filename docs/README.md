## 前言

量子计算正从实验室走向工程。超导处理器已突破 1000 量子比特，纠错在实验上可行，变分算法在化学模拟和优化中展现了潜力。现在学，是跟上这波变化的合理选择。

但一本适用的教材应该什么样？

量子计算横跨物理学（量子力学、超导器件、微波工程）、计算机科学（算法、复杂度、信息论）、数学（线性代数、群论、概率论）和工程学（控制电子学、低温系统、信号处理）。传统教材往往偏重一端：算法忽视硬件，物理忽视计算视角，或理论完整但缺乏实践联系。

本书原则：**不回避任一层的复杂性，但需要时才引入**。

第二个困境是理论与实践脱节。许多教材止于"理想门 + 数学推导"，读者知道 Deutsch 算法，但不知道它在真实芯片上如何跑。另一极端是硬件手册式内容，缺理论框架。

本书的桥梁是**三层递进**：

1. **抽象层**：量子比特、门、电路模型、算法——不依赖具体硬件
2. **实现层**：超导量子比特物理、门操作的硬件实现、控制脉冲、读出
3. **编译层**：算法如何映射到受限拓扑，错误如何缓解和纠正

读完本书，你能理解一个算法的完整旅程：从量子线路图到 AWG 产生的微波脉冲，再到 JPA 放大后的读出信号。

第三，这本书对读者诚实。量子计算是一项**正在构建中的技术**。书中明确区分：哪些是已建立的理论（Shor 算法、纠错码理论），哪些是活跃研究方向（量子机器学习、错误缓解），哪些是开放挑战（大规模容错、拓扑量子比特）。每个主题标注"成熟度"——判断哪些可以"拿来用"，哪些仍在发展。

**谁适合读这本书？**

- 理工科一二年级数学基础就够了：线性代数、微积分、基础概率论。**不需要先修量子力学**——第 2 章会从头建立所需框架。
- "可及"意味着：你能跟上所有主要推导。第一章提供 100+ 个带步骤的数值例子，花 3–4 小时认真读完，瓶颈就过了。
- **不需要编程。** 全书以纸笔推导为主，电路和算法都以数学形式给出。如果你希望动手，模块三/四可以配合 Qiskit 或 Cirq 做练习；模块五可用 Aer 模拟噪声；模块六的参数来自真实实验，不做模拟。初学者建议先做纸笔推导，熟悉后再用编程验证。
- 学完你能做什么？理解量子计算的核心原理和工程约束，具备阅读 arXiv 论文的基础，能判断哪些方向已经成熟、哪些仍在探索。如果你做相关研究或工程，这将是一份结构化的技术地图。

### 书写约定

- **`粗体`**：首次引入的关键术语，在知识点索引中可查
- **$\text{LaTeX}$ 公式**：全书数学表达式统一使用 LaTeX 排版，支持 KaTeX 或 MathJax 渲染
- **例 X.Y**：具体数值例子，帮助理解抽象概念。建议先尝试自己计算，再对照步骤
- **证明/推导**：关键定理的证明单独列出，包含详细步骤
- **本章习题**：每章末尾有分级习题，标 * 的为扩展题
- **知识点索引**：每章末尾的术语索引包含中英文对照
- **超导实现视角**（模块三 ch07–ch12、模块五 ch21–ch24）：章末、`## 本章习题` 之前的固定接口卡，**不替代** ch12 / ch20 / ch25–ch27 的系统讲解

#### 超导实现视角（接口卡）

这是什么：模块三（ch07–12）与模块五（ch21–24）的每章末尾、`## 本章习题` 之前，有一个带 `!!! tip` 标记的方框。它的作用是把本章抽象内容**映射到超导硬件**——比如"单比特门"对应"用微波脉冲驱动 Transmon 的 $|0⟩\leftrightarrow|1⟩$ 跃迁"。

**格式**（四个字段）：

| 字段 | 内容 |
|------|------|
| 对象 | 本章抽象概念的物理对应 |
| 超导载体 | 对应的具体器件 / 物理自由度 |
| 操作要点 | 实现该操作的 1–3 句关键约束（如何驱动、测量，或主要噪声） |
| 深读 | 在 ch12 / ch20 / ch25–27 中进一步阅读的小节指针 |

**定位**：轻量穿线。接口卡是提示，不是独立章节。要深入操作细节，去 ch12（门物理总汇）、ch20（编译与错误缓解桥）、ch25–27（器件、控制、读出）。

### 阅读建议

1. **不要跳过例子**：本书有 100+ 个数值例子，含中间步骤。它们是正文的一部分，不是点缀。
2. **同步验证**（可选）：如果你有 Python 环境，可以用 Qiskit 或 Cirq 运行书中电路来验证。不需要这个也能读。
3. **交叉引用**：`§X.Y` 指向相关章节。做习题后建议回看。
4. **习题分类**：基础题（巩固计算）→全部完成；应用题（连接场景）→尽量做；推导题（标 *）→锻炼数学推导。
5. **配套资源**：习题解答分册（`solutions/`，所有习题有详细推导）。代码仓库（含 Jupyter Notebook、Qiskit 示例、校准数据分析脚本）正在建设。

#### 我需要编程吗？

**不需要。** 重点是原理理解，所有内容以数学形式给出。

但若希望动手——
- 模块三、四：配合 Qiskit / Cirq 效果最佳。标 * 的习题有配套编程练习
- 模块五：可用 Qiskit Aer 模拟噪声
- 模块六：硬件参数来自真实实验，不做模拟

建议**先纸笔推导，再编程验证**。
