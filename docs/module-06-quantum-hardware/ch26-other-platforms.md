# 第2章 其他量子计算平台对比

> **本章导读**
>
> 第1章详细介绍了超导量子比特——当前最成熟、量子比特数量最多的技术路线。但超导并非唯一选择。离子阱、光子、硅基自旋、拓扑、中性原子等体系各有独特优势，在某些维度上甚至超越超导。本章俯瞰全景，逐一剖析每种平台的物理原理、核心指标、优缺点，并与超导路线定量对比，帮助读者建立完整的硬件选型视野。

## 2.1 离子阱量子比特

### 2.1.1 物理原理

离子阱量子比特利用**单个带电原子（离子）**在真空中被电磁场囚禁，以离子的两个内能级作为量子比特：

- **囚禁**：射频四极阱（Paul阱）或表面阱产生赝势，将离子悬浮在真空中（$10^{-11}$ Torr）
- **量子比特编码**：通常用基态 $|0\rangle$ 和亚稳态 $|1\rangle$ 表示，例如 $^{40}\text{Ca}^+$ 的 $S_{1/2}$ 和 $D_{5/2}$ 能级
- **单比特门**：用聚焦激光或微波驱动 Rabi 振荡，实现任意单比特旋转
- **两比特门**：通过共有运动模（phonon）作为数据总线，利用**Molmer-Sørensen门**实现纠缠——激光束调谐到边带频率，产生受控的 $XX$ 型相互作用

**示意图：**

```
激光束
   ↓
  ┌────┐
  │ ●  │  ← 囚禁离子（$^{40}\text{Ca}^+$）
  └────┘
  电极 ── RF 电压
```

离子之间的**库仑排斥**使一串离子保持确定间距，共有运动模式将信息传递给所有离子，实现多比特纠缠。

### 2.1.2 核心指标

| 指标 | 典型值 | 说明 |
|------|--------|------|
| 相干时间 $T_2$ | $\sim 10$ min | 所有平台中最高——离子几乎不与环境耦合 |
| 单比特门保真度 | $> 99.99\%$ | 激光驱动精度极高 |
| 两比特门保真度 | $> 99.9\%$ | Molmer-Sørensen门 |
| 门速度 | $\sim 1$–$10$ μs | 受激光-运动耦合强度限制 |
| 量子比特数量 | $\sim 50$（当前） | 离子串/网格扩展受困于运动模式拥挤 |

### 2.1.3 优缺点

**优势：**
1. **极端长相干时间**：离子与环境几乎无耦合，$T_2$ 达分钟级，远超超导（$\sim 100\text{--}300$ μs）
2. **全同量子比特**：每个离子都是天然相同的原子，不存在超导芯片的制造参数漂移
3. **高保真门**：单比特 $> 99.99\%$，两比特 $> 99.9\%$，与超导最好水平相当
4. **室温运行**：不需稀释制冷机（仅需真空）

**劣势：**
1. **门速度慢**：比超导慢 $10^3$–$10^4$ 倍（超导门 $\sim 10\text{--}100$ ns）
2. **扩展困难**：离子串的运动模式随离子数线性增长，模式频率挤在一起；
   超过 $\sim 50$ 个离子后寻址时产生串扰
3. **激光系统复杂**：需要多束稳定激光（频率、相位、指向稳定），体积庞大
4. **阱制造挑战**：表面阱电极间距仅数十微米，射频加热效应影响门保真度

### 2.1.4 与超导对比

| 维度 | 离子阱 | 超导 |
|------|--------|------|
| 相干时间 | $\sim 10$ min | $\sim 300$ μs |
| 门速度 | μs 级 | ns 级 |
| 保真度 | 极高 | 极高 |
| 扩展性 | 中等（$\sim 50$） | 高（$> 1000$） |
| 温度要求 | 室温（真空） | 20 mK |
| 制造难度 | 中等（阱+激光） | 高（微纳加工+制冷） |

**一句话**：离子阱保真度和相干时间无敌，但速度慢、难扩展；超导速度快、好扩展，但相干时间短、需要极低温。二者互补。

## 2.2 光量子计算

### 2.2.1 物理原理

光量子计算以**光子**（光的量子）作为量子比特载体。光子有多个自由度可以编码量子信息：

- **偏振编码**：$|H\rangle$（水平偏振）、$|V\rangle$（垂直偏振）
- **路径编码**：光子出现在路径 $a$ 或路径 $b$
- **时间仓编码**：光子早到或晚到

**线性光学量子计算**（LOQC）的核心元件：

1. **单光子源**：确定性或概率性产生单个光子（量子点、自发参量下转换 SPDC）
2. **线性光学元件**：分束器（BS）、偏振分束器（PBS）、波片、相位延迟器
3. **测量**：单光子探测器（SPAD、超导纳米线探测器 SNSPD）

**示意图（Hong-Ou-Mandel 干涉）：**

```
  光子1 ─╲
         ╱─── 探测器0
  光子2 ─╲   探测器1
   
   分束器（BS）
```

两个全同的光子同时入射到 50:50 分束器——**Hong-Ou-Mandel 效应**：两个光子必定从同一出口输出，产生量子干涉。这是光量子两比特门的物理基础。

### 2.2.2 核心指标

| 指标 | 典型值 | 说明 |
|------|--------|------|
| 单光子源效率 | $> 80\%$（量子点） | 概率性源效率低 |
| 探测器效率 | $> 95\%$（SNSPD） | 超导纳米线探测器 |
| 门保真度 | $\sim 99\%$ | 低于离子阱和超导 |
| 光子损耗 | 每元件 $1\text{--}10\%$ | 光路损耗累积严重 |
| 量子比特数量 | $\sim 20$（实测） | 需要大量光子 |

### 2.2.3 优缺点

**优势：**
1. **室温运行**：光子传播几乎不受温度影响，不需要制冷
2. **极低退相干**：光子与环境相互作用极弱，天然长相干
3. **高维编码**：一个光子可编码多个量子比特（通过轨道角动量等）
4. **天然网络兼容**：光子通过光纤传输，易于连接远距离量子节点

**劣势：**
1. **两比特门困难**：光子间几乎不相互作用——需要**测量诱导门**（通过投影测量实现门操作），这是概率性的
2. **可扩展性差**：每个额外的量子比特需要更多光学元件，损耗随规模指数增长
3. **单光子源不完美**：确定性单光子源仍在发展，多数方案依赖概率性源
4. **体积巨大**：光路需要精密对准和隔离振动，难以小型化

### 2.2.4 与超导对比

| 维度 | 光子 | 超导 |
|------|------|------|
| 运行温度 | 室温 | 20 mK |
| 相互作用 | 极弱（门困难） | 强（电容耦合） |
| 相干时间 | 极长（光纤延时可接受） | 短（μs 级） |
| 可扩展性 | 困难（元件爆炸） | 好（光刻工艺） |
| 网络集成 | 天然适合 | 需转换接口 |

**一句话**：光子适合量子通信和网络，作为计算平台的门保真度和扩展性目前落后超导。

## 2.3 硅基自旋量子比特

### 2.3.1 物理原理

硅基自旋量子比特利用**电子或空穴的自旋**在硅晶体中编码量子信息。核心器件是**量子点**——一个纳米尺度的势阱，通过金属栅极电压在硅/硅锗（Si/SiGe）异质结中形成。

- **量子比特编码**：电子自旋 $|\uparrow\rangle$（$m_s = +\tfrac12$）和 $|\downarrow\rangle$（$m_s = -\tfrac12$）
- **单比特门**：电子自旋共振（ESR）——施加与自旋 Zeeman 分裂共振的微波磁场，驱动 Rabi 振荡
- **两比特门**：通过交换相互作用（Heisenberg 耦合）实现。两个相邻量子点的电子波函数重叠时，产生自旋-自旋耦合：

$$
\hat{H}_{\text{ex}} = J \, \hat{\boldsymbol{S}}_1 \cdot \hat{\boldsymbol{S}}_2
$$

其中 $J$ 是交换耦合强度，通过调节中间栅极电压控制。

**示意图：**

```
  栅极1    栅极2    栅极3
  ┌───┐    ┌───┐    ┌───┐
  │   │    │   │    │   │
  └───┘    └───┘    └───┘
  ───── Si/SiGe 异质结 ─────
  量子点1 ── 量子点2
    ↑          ↓
```

### 2.3.2 核心指标

| 指标 | 典型值 | 说明 |
|------|--------|------|
| 相干时间 $T_2^*$ | $\sim 1$–$100$ μs | 同位素纯化 $^{28}\text{Si}$ 可达 ms |
| 单比特门保真度 | $> 99.9\%$ | 已接近超导水平 |
| 两比特门保真度 | $> 99\%$ | 受电荷噪声限制 |
| 门速度 | $\sim 10$–$100$ ns | 与超导相当 |
| 量子点尺寸 | $\sim 50$ nm | 极紧凑 |

### 2.3.3 优缺点

**优势：**
1. **极小的物理尺寸**：量子点仅数十纳米，芯片可容纳数百万量子比特
2. **借用 CMOS 工艺**：制造与现有半导体产业链高度兼容，这是超导无法比拟的
3. **长相干（同位素纯化）**：天然硅中 $^{29}\text{Si}$ 有核自旋（噪声源），纯化后 $T_2$ 可达秒级
4. **全电学控制**：无需激光，用电压脉冲即可操作，便于集成控制电路

**劣势：**
1. **电荷噪声敏感**：量子点对界面电荷涨落（$1/f$ 噪声）敏感，影响门保真度
2. **量子比特均匀性差**：每个量子点的尺寸和势阱深度有差异，需要逐个校准
3. **低温运行**：通常需要 $\sim 100$ mK 稀释制冷机
4. **读出保真度较低**：自旋态通过电荷传感器读出，保真度 $\sim 98\%$，低于超导的 $> 99\%$

### 2.3.4 与超导对比

| 维度 | 硅基自旋 | 超导 |
|------|----------|------|
| 尺寸 | $\sim 50$ nm | $\sim 100$ μm |
| 制造集成 | CMOS 兼容 | 需特殊工艺 |
| 相干时间 | μs–ms | μs |
| 门速度 | ns 级 | ns 级 |
| 温度 | $\sim 100$ mK | $\sim 20$ mK |
| 保真度 | 略低 | 高 |

**一句话**：硅基自旋的最大王牌是**规模化和制造兼容性**；只要解决电荷噪声和均匀性问题，有望成为"量子芯片的 CMOS"。

## 2.4 拓扑量子比特

### 2.4.1 物理原理

拓扑量子比特基于**非阿贝尔任意子**（anyons）——二维系统中的准粒子激发，其交换统计既非玻色子也非常费米子。

核心思想：量子信息存储在**任意子的编织世界线**中，而非某个具体粒子的局部自由度。

- **马约拉纳零模**（Majorana zero mode, MZM）：在拓扑超导体中，准粒子激发是其自身的反粒子。两个马约拉纳零模 $γ_1, γ_2$ 构成一个费米子模式：

$$
\gamma_i^\dagger = \gamma_i, \quad \{\gamma_i, \gamma_j\} = 2\delta_{ij}
$$

一个量子比特需要四个马约拉纳零模，编码在它们的**占据奇偶性**上：

$$
|0\rangle = |n_{12}=0, n_{34}=0\rangle, \quad |1\rangle = |n_{12}=1, n_{34}=1\rangle
$$

- **编织操作**：将马约拉纳零模的方位交换，实现逻辑门。编织操作只改变系统的拓扑状态，不受局部微扰影响。

**示意图：**

```
  路径1       路径2
    ╱ ╲       ╱ ╲
   ╱   ╲     ╱   ╲
  ╱     ╲═══╱     ╲
  γ1      γ2      γ3      γ4
  
  ─── 编织顺序：γ1 ↔ γ2 交换 ───
```

### 2.4.2 核心指标

| 指标 | 现状 | 说明 |
|------|------|------|
| 相干时间 | 理论上无穷 | 拓扑保护免受局部噪声 |
| 门保真度 | 尚未演示逻辑门 | 编织操作未实现 |
| 温度 | 极低温（$\sim 10$ mK） | 拓扑超导体的超导能隙限制 |
| 量子比特数量 | 0（可操作量子比特） | 仅在纳米线中观测到马约拉纳模信号 |

### 2.4.3 优缺点

**优势（理论）：**
1. **拓扑保护**：局部噪声（电荷噪声、磁通噪声）无法改变拓扑量子态——原则上**无退相干**
2. **纠错自然嵌入**：编织操作本身就实现容错门，不需要额外纠错层
3. **容错阈值高**：对物理门保真度要求远低于其他平台（$< 1\%$ 即可工作）

**劣势（现实）：**
1. **马约拉纳零模未被证实**：当前所有"观测"都存在争议（如微软 2018 年的 Nature 论文后被撤稿）
2. **编织操作未实现**：即使存在马约拉纳模，如何操控它们编织仍是巨大的实验挑战
3. **极低温度**：比超导还低（$\sim 10$ mK），制冷系统更复杂
4. **量子比特太少**：一个编织操作需要至少 4 个马约拉纳模，当前只能制造 1–2 个并检测信号

### 2.4.4 与超导对比

| 维度 | 拓扑 | 超导 |
|------|------|------|
| 技术成熟度 | 基础研究 | 工程验证 |
| 退相干 | 理论零 | 有限 |
| 温度 | $\sim 10$ mK | $\sim 20$ mK |
| 门保真度 | 未演示 | $> 99.9\%$ |
| 扩展性 | 未知 | 已验证数百比特 |

**一句话**：拓扑量子比特是"圣杯"——成功后无可匹敌，但道路漫长且基础物理尚未完全确认。

## 2.5 中性原子体系

### 2.5.1 物理原理

中性原子量子比特利用**单个中性原子**（如 $^{87}\text{Rb}$、$^{133}\text{Cs}$、$^{171}\text{Yb}$）通过光镊（optical tweezers）捕获阵列，以原子的内能级作为量子比特。

- **捕获**：高度聚焦的激光束（光镊）产生光学偶极阱，单个原子被捕获在衍射极限焦点处
- **量子比特编码**：超精细能级（基态 $F$ 的不同 $m_F$ 分量），对磁场噪声不敏感
- **单比特门**：拉曼激光或微波驱动
- **两比特门**：利用**里德堡态**（Rydberg 态）——将原子激发到主量子数 $n \gg 1$ 的高态，此时原子半径达 $\sim 1$ μm（基态仅 $\sim 0.1$ nm），原子间产生极大的偶极-偶极相互作用：

$$
V_{\text{vdW}} = \frac{C_6}{R^6} \quad \text{或} \quad V_{\text{dd}} = \frac{\mu^2}{R^3}
$$

利用**里德堡阻塞**（Rydberg blockade）效应：当原子 A 被激发到里德堡态时，其电场使邻近原子 B 的能级偏移，阻止 B 同时被激发——这实现了受控门操作。

**示意图：**

```
  光镊阵列
  ┌───┐ ┌───┐ ┌───┐
  │ ● │ │ ● │ │ ● │  ← 单个 $^{87}\text{Rb}$ 原子
  └───┘ └───┘ └───┘
    ↓       ↓       ↓
  激光束  激光束  激光束
  
  当原子被激发到里德堡态：
  ●───●───●
  ╰──阻塞半径──╯
```

### 2.5.2 核心指标

| 指标 | 典型值 | 说明 |
|------|--------|------|
| 相干时间 $T_2$ | $\sim 1$–$10$ s | 超精细编码对噪声不敏感 |
| 单比特门保真度 | $> 99.99\%$ | 与离子阱相当 |
| 两比特门保真度 | $\sim 99.5\%$ | 受里德堡态寿命和激光线宽限制 |
| 门速度 | $\sim 100$ ns–1 μs | 里德堡激发快，但需激光冷却 |
| 捕获原子数 | $> 200$（阵列） | 通过光镊阵列重组 |

### 2.5.3 优缺点

**优势：**
1. **大规模阵列**：光镊阵列可在 $\text{mm}^2$ 面积捕获数百个原子，扩展性好
2. **长相干时间**：超精细基态对噪声免疫，$T_2$ 达秒级
3. **重排能力**：通过移动光镊可以重新排列原子阵列（消除空位），提高产率
4. **全同量子比特**：所有原子相同，无制造差异
5. **里德堡门快速**：里德堡相互作用的强度使门速可达 $\sim 100$ ns

**劣势：**
1. **激光系统复杂**：需要多波长激光（冷却、捕获、操作、里德堡激发）
2. **原子装载概率性**：每个光镊捕获原子的概率 $\sim 50\%$，需要量子纠错或重排补偿
3. **运动退相干**：原子温度需要冷却到 $\sim 10$ μK 以下，否则运动导致退相干
4. **受限的连通性**：里德堡阻塞只在邻近原子间有效，远程门需要中间原子辅助

### 2.5.4 与超导对比

| 维度 | 中性原子 | 超导 |
|------|----------|------|
| 量子比特一致性 | 完全相同 | 有制造差异 |
| 相干时间 | $\sim$ s | $\sim$ μs |
| 门速度 | ns–μs | ns |
| 阵列尺寸 | 数百（增长快） | 千级 |
| 制造要求 | 光镊+激光 | 光刻+微纳加工 |
| 温度 | $\sim 10$ μK（激光冷却） | 20 mK |

**一句话**：中性原子是近年**增长最快的路线**——结合了离子阱的高保真和长相干，又避免了固态制造的不可重复性；但激光系统复杂度是主要瓶颈。

### 2.6.1 如何选择？

没有一种平台在所有维度上占优。选择取决于应用场景：

- **近期量子优势**：超导路线最有望——量子比特数量多，门保真度够用，NISQ 算法可运行
- **高保真需求**：离子阱提供最优的门保真度和长相干，适合**量子化学模拟**
- **量子网络/通信**：光子路线天然适合，已用于量子密钥分发和纠缠分发
- **大规模集成**：硅基自旋和中性原子有最好的规模潜力，但分别面临电荷噪声和激光系统瓶颈
- **终极容错**：拓扑量子比特是理论目标，但基础研究仍需重大突破

### 2.6.2 未来趋势

1. **混合架构**：将不同平台的优势结合——超导用于计算、光子用于网络、离子阱用于存储
2. **模块化**：各平台都在向模块化方向发展（连接多个小规模芯片/阱/阵列）
3. **纠错进展**：一旦超导或离子阱实现逻辑量子比特的实用纠错，其他路线将面临追赶压力

**本章小结**

- 离子阱：保真度和相干时间冠军，但门速度慢、比特数受限
- 光子：网络兼容好、室温运行，但两比特门困难、损耗大
- 硅基自旋：CMOS 兼容潜力最大，电荷噪声和均匀性待解决
- 拓扑：理论上无退相干，但基础物理未证实
- 中性原子：近年黑马，阵列扩展快、保真度高，激光系统是瓶颈
- 综合对比表明：没有万能路线，混合架构是长期趋势
