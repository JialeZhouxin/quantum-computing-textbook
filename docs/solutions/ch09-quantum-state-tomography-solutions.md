# 习题解答 · 第9章 量子态层析（QST）

---

### 基础题

**3.1** $P(0) = 0.64$，$P(1) = 0.36$。

$r_z = P(0) - P(1) = 0.64 - 0.36 = 0.28$

**3.2** 单比特 QST，$P(+x) = 0.90$，$P(-x) = 0.10$。

$r_x = P(+x) - P(-x) = 0.90 - 0.10 = 0.80$

**3.3** $\rho = \begin{pmatrix} 0.75 & 0.25 \\ 0.25 & 0.25 \end{pmatrix}$

$\text{Tr}(\rho) = 0.75 + 0.25 = 1$ ✓
$\rho^\dagger = \rho$ ✓

半正定性：本征方程 $(0.75 - \lambda)(0.25 - \lambda) - 0.0625 = 0$
$\lambda^2 - \lambda + 0.1875 - 0.0625 = 0$，$\lambda^2 - \lambda + 0.125 = 0$
$\lambda = (1 \pm \sqrt{1 - 0.5})/2 = (1 \pm \sqrt{0.5})/2 \approx 0.854, 0.146$

$\lambda \geq 0$ ✓ → **合法**。

**3.4** QST 数据：三个基方向都得到 $P(+) = P(-) = 0.5$。

**(a)** $r_x = 0$，$r_y = 0$，$r_z = 0$。布洛赫向量 $\vec{r} = (0, 0, 0)$，长度 $|\vec{r}| = 0$。

**(b)** $\rho = \frac12 I = \frac12\begin{pmatrix}1&0\\0&1\end{pmatrix}$

**(c)** 最大混态。对所有测量方向等概率——系统不包含任何关于态的信息。

**3.5** 两比特 $XX$ 基测量。

$\langle XX \rangle = P(++) + P(--) - P(+-) - P(-+)$
$= (50/200 + 50/200 - 50/200 - 50/200) = 0$

### 提高题

**3.6** $\rho = \frac12(I + \vec{r} \cdot \vec{\sigma})$。

$\rho^2 = \frac14(I + 2\vec{r}\cdot\vec{\sigma} + (\vec{r}\cdot\vec{\sigma})^2)$

利用 $(\vec{r}\cdot\vec{\sigma})^2 = |\vec{r}|^2 I$：

$\rho^2 = \frac14(I + 2\vec{r}\cdot\vec{\sigma} + |\vec{r}|^2 I) = \frac14((1+|\vec{r}|^2)I + 2\vec{r}\cdot\vec{\sigma})$

$\text{Tr}(\rho^2) = \frac14((1+|\vec{r}|^2)\text{Tr}(I) + 2\text{Tr}(\vec{r}\cdot\vec{\sigma})) = \frac14(2(1+|\vec{r}|^2) + 0) = \frac12(1+|\vec{r}|^2)$

**3.7** $N = 2500$，$n_0 = 1200$，$n_1 = 1300$。

$r_z = \frac{n_0 - n_1}{N} = \frac{-100}{2500} = -0.04$

标准差：$\sigma_{r_z} = \sqrt{\frac{1 - r_z^2}{N}} = \sqrt{\frac{1 - 0.0016}{2500}} \approx \sqrt{0.000399} \approx 0.020$

$r_z = -0.04 \pm 0.020$（1σ 置信区间）。与 0 的偏差不显著（约 2σ）。

**3.8** 仅用 $Z$ 和 $X$ 基不能区分某些态。

例如 $|+\rangle_Y = \frac{1}{\sqrt{2}}(|0\rangle + i|1\rangle)$ 和 $|-\rangle_Y = \frac{1}{\sqrt{2}}(|0\rangle - i|1\rangle)$：
- 在 $Z$ 基：$P(0) = P(1) = 0.5$（相同）
- 在 $X$ 基：$P(+) = P(-) = 0.5$（相同）

只有 $Y$ 基测量能区分它们。$\langle Y\rangle$ 需要 $Y$ 基测量。三组正交基（$X, Y, Z$）是信息完备的。

**3.9** 已知是纯态时，只需 $2d - 2 = 2$ 个实参数量（布洛赫球上的 $\theta, \phi$）。所以只需要 2 个独立的测量（如 $X$ 和 $Z$ 基），$Y$ 基可由归一化条件推断。但实验上通常仍测三组以交叉校验。

**3.10** 大规模系统不会使用完整 QST。

原因：需要的测量数随比特数指数增长（$4^n - 1$ 个参数）。对于 $n=50$，完整 QST 需要约 $10^{30}$ 次测量——宇宙年龄也完不成。

替代方法：直接保真度估计（仅需 $O(1)$ 个 Pauli 测量，已知目标态时）、经典阴影层析（可预测大量物理量）、压缩传感（利用低秩假设）、交叉熵基准测试等。
